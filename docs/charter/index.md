# 过学总纲

> **生活成本可以低，生活品质不能低。**
>
> 省钱不是目的，优化生活资源配置才是目的。

这是《过学总纲》第一版。具体措辞可以继续讨论，最高纲领是所有实践和新论的共同判断起点。

## 一、过学研究什么

普通人怎样用更低的生活成本、更低的维护成本、更少的无效消耗，获得、维持甚至提升真正的生活品质。

我们关心的不只是购物账单。睡眠、饮食、居住、身体状态、时间安排、财务余地，以及真正重要的人际关系，都是日子的一部分。

把钱省下来却每天更累、更不安全、更难受，账面好看，生活未必划算。

## 二、什么是“过的人”

“过的人”把日子当自己的事：知道什么对自己重要，敢砍掉不重要的成本，也愿意为真正重要的需求留出资源。

这不是身份等级。收入高低、用新物还是二手、租房还是买房，都不能直接决定一个人是不是“过的人”。

你可以有爱好、讲究美感、喜欢好东西。过学要问的是：这些投入真的让你过得更好吗？

## 三、为什么零散方法值得整理

中文互联网里出现了许多生活主张：大水、长睡眠、薄肌、低成本租房、二手、租万物……

它们回应的现实问题各不相同：喝什么、怎么休息、怎么运动、住哪里、怎么买、什么时候不必买。

这些主张可能包含有用的方法，也可能有模糊说法或被夸大的部分。名称本身不等于证据，流行也不等于人人适用。

过学尝试把有价值的方法背后的共同规律总结出来，让人遇到新方法时，有一套能用的判断办法。我们不编造它们的作者、起源、流行时间或传播数据；准确出处待补充的地方，就明确写出来。

## 四、过学是道，具体理论是术

**“道”回答：什么值得、什么该守住、应该怎么判断。**

**“术”回答：眼前这个问题，可以怎么做。**

过学的层级是：

1. **最高纲领：**生活成本可以低，生活品质不能低。
2. **基本原则：**十条原则，帮我们判断一项投入或方法值不值。
3. **具体实践：**围绕喝水、睡眠、运动、居住、购买和使用，给出可尝试的办法。
4. **边界：**守住健康、安全、基本生活质量和长期利益。
5. **新论吸纳：**拆开新主张，核对来源、收益、风险和适用条件，再决定如何收录。

收录一个理论，是认可其说明清楚、条件明确的实践部分，不代表赞同这个名字下的所有说法。

## 五、我们有四种资源

| 资源 | 容易忽略的成本 | 一个日常问题 |
| --- | --- | --- |
| 钱 | 利息、运费、维修、持续订阅 | 买得便宜，后面还要花多少？ |
| 时间 | 通勤、比价、跑腿、等待 | 为了省这笔钱，我要多花多久？ |
| 精力 | 清洁、搬运、学习、售后 | 用上它以后，我会轻松还是更累？ |
| 注意力 | 消息提醒、促销追踪、反复纠结 | 它是不是一直占着我的脑子？ |

这四种资源可以互相换，但没有统一汇率。一个人愿意花时间修东西，另一个人更需要把时间留给孩子，两者都可能合理。

别把时间、精力和注意力当成免费赠品。

## 六、生活去溢价：去掉不带来价值的那一层

溢价指你为某个东西额外支付的成本。它可能来自可靠品质、方便服务，也可能来自排场、人设、包装和别人的眼光。

**过学要去掉的是对你无效的溢价。**

同样能满足需求的东西，如果只是换了一个“看起来更有身份”的标签，却让你承担更高成本，值得重新考虑。

但如果更高价格确实换来更可靠的质量、更省心的使用或你珍视的美感，它可能有实际价值。不能看到价格高就宣布违规。

“这不是消费降级，这是生活去溢价。”这句话的前提，是核心体验确实守住了。

## 七、维护成本：买回来之后，生活才开始算账

有些东西买时不贵，用起来却要不断清理、充电、修理、续费和整理。有些生活安排看着体面，维持起来却需要长期扮演、应付和解释。

维护成本就是：为了让一个物品、安排或状态继续正常存在，你要持续付出的资源。

低维护不等于什么都不管。定期维护车辆、整理重要账单、照顾关系，可能是在避免更大的后续成本。要减少的是无效折腾，不是必要责任。

## 八、核心需求与表面需求

先问“我要解决什么”，再问“我要买什么”。

想换更贵的房子，真实需求可能是安静、采光、通勤便利；想换手机，可能只是电池不够用；想添一件衣服，可能是需要一件舒适耐穿的日常衣物。

把问题说清楚，才有机会找到更合适的办法。维修、调整、借用、租赁、二手或购买，都只是选项。

表面需求也不必一律否定。喜欢某个设计、享受收藏，本身可以是真实需求。关键是承认自己的动机，知道代价，不把别人的期待伪装成自己的刚需。

## 九、真正的高性价比，按生活算

性价比不是“折扣最大”，也不是“参数最多”。

**它要看实际使用价值、使用频率、使用期限、全部成本，以及你放弃了什么。**

一张 3000 元床垫，如果每天睡 8 小时，确实改善体验，预算也承担得起，可能非常符合过学。价格只是判断的一部分，这不是对某个价位或产品效果的保证。

一件很贵、很少使用、主要拿来展示的商品，可能占用了更重要需求的资源。

同一件商品，对不同的人可以得出不同结论。一个人的刚需，不会自动变成所有人的购物清单。

## 十、便宜和贵，都不能直接判卷

便宜的东西若不安全、不耐用、根本不需要，买它未必划算。

贵的东西若持续解决核心问题、降低长期成本，而且没有挤压必要支出，也可能值得。

先明确你要什么，再看有没有更合适的方案。过学不会设一条固定价格线，把所有人的生活拦在同一个预算里。

## 十一、过学与几个常见说法的区别

| 说法 | 过学怎样看 |
| --- | --- |
| 消费降级 | 消费金额下降，不一定代表体验下降，也不一定代表变好。过学判断的是品质和资源配置。 |
| 极端节俭 | 如果为了省钱长期忍受本可避免的健康、安全或基本生活问题，已经偏离最高纲领。 |
| 躺平或摆烂 | 可以少做无效竞争，也要认真照顾身体、生活和应尽的责任。过学关心实际结果。 |
| 低欲望 | 想要的东西少，可以降低负担；想要的东西多，也可以先分清轻重。过学不要求统一欲望水平。 |
| 反消费 | 买、修、借、租、用二手都可以。每种方式都要根据真实需求和总成本判断。 |

## 十二、过学的十条基本原则

| 编号 | 原则 | 先问自己一句 |
| --- | --- | --- |
| P01 | 生活品质优先原则 | 省下成本后，我的日子还好吗？ |
| P02 | 去无效溢价原则 | 多付的钱，给我带来了什么？ |
| P03 | 核心需求优先原则 | 我到底要解决哪个问题？ |
| P04 | 低维护原则 | 后面还要持续折腾多少？ |
| P05 | 资源集中原则 | 它会不会挤掉更重要的事？ |
| P06 | 长期成本原则 | 全部账算完，还划算吗？ |
| P07 | 真实使用价值原则 | 我会真的用上它吗？ |
| P08 | 因人而异原则 | 这个办法适合我的条件吗？ |
| P09 | 不以吃苦为荣原则 | 这份苦有必要承受吗？ |
| P10 | 不为别人眼里的体面买单原则 | 如果没人看见，我还想这样选吗？ |

每条的解释、正反例与例外，见[《过学基本原则》](/principles/)。

## 十三、有些底线，不拿来换便宜

过学不能为了低成本牺牲：

- 健康与安全。
- 基本营养与合理睡眠。
- 基本居住质量与必要医疗。
- 长期财务安全。
- 真正重要的人际关系。

短期便宜、长期成本更高的方案，通常不符合过学。涉及健康或医疗的问题，不能用网络口号替代适合个人情况的专业判断。

现实里资源紧张，有些人暂时没有更好的选项。这不意味着他们不够会过。我们讨论的是怎样逐步改善条件，不拿生活困难给人贴标签。

## 十四、新理论怎么进总部

先把主张拆清楚：它解决什么问题？实际怎么做？有哪些来源？省下的是哪种成本？失去的又是什么？

然后对照十条原则，检查健康、安全、长期风险和适用条件。与已有理论重复，可以合并或补充，不必每个新名字都立一派。

当前收录由人工维护，状态包括**正式收录、有条件收录、观察中、不予收录**。结论公开写明理由，补充可靠信息后可以重审。未来 Agent 可以协助整理和分析，正式收录仍须经过人工复核。

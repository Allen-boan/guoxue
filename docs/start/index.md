# 第一次来到过学？

## 30 秒，先把话说清楚

**过学研究的是：普通人怎样用更低的生活成本、更低的维护成本、更少的无效消耗，获得、维持甚至提升真正的生活品质。**

最高纲领只有一句：

> **生活成本可以低，生活品质不能低。**

钱该省就省。睡得舒服、吃得合理、住得安全、身体有照顾，这些也该认真。

“不是少花钱，而是少给不重要的东西花钱。”

## 什么是“过的人”

买东西先想“我用不用得上”，住哪里先想“我过得舒不舒服”，肯为真正重要的东西花钱，也敢不为面子买单。

这样的普通人，我们叫“过的人”。这是一种自愿认同，不是收入分组，也没有入门消费门槛。

**混的人混社会，我们过日子。**

## 为什么还要搞一门学问

互联网里，大水、长睡眠、薄肌、低成本租房、二手、租万物……名字不同，讨论的常常是同一件事：怎么让自己的日子更划算、更舒服、更少折腾。

这些方法值得逐个看。过学想再往上走一步：把它们背后的共同逻辑讲明白，遇到新方法时，也能知道该学什么、哪里不能照搬。

**过学是“道”，具体理论是“术”。** 有方法，也有判断方法的尺子。

## 一个例子，立刻懂

同样是 3000 元的床垫：

- 每天使用，确实更舒服，预算也承受得住：可能值得。
- 只是为了拍照显得讲究，实际睡着不舒服：再贵也没买到生活品质。

过学不拿统一价格线给人打分。核心判断是**值不值**：它给你的生活带来了什么，你付出的总成本又是什么。

## 你可以这样逛

1. **想知道自己是不是这类人：**看[你是不是过的人](/identity/)。
2. **想把逻辑看明白：**读[《过学总纲》](/charter/)，再看[十条基本原则](/principles/)。
3. **想今天就试一件事：**去[《过学实践篇》](/practice/)，挑一个与你有关的问题。
4. **想知道新说法靠不靠谱：**看[《过学新论》](/new/)和[总部最新决议](/decisions/)。

不需要一次读完。先解决眼前一个真实问题，就算开学了。

::: tip 先记住这条边界
通过牺牲健康、安全、基本营养、合理睡眠或长期财务安全换来的便宜，不符合过学。短期省下的账，不能让以后加倍还。
:::

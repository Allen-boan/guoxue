# 2.10 物品生命周期

买东西时常问好不好用，搬家或停用时才发现，卖不掉、搬不动、资料取不出，同样会影响生活。付款只是这段关系的开始，结束时也需要留有办法。

<a id="guide-exit-cost"></a>

## 2.10.1 考虑退出成本

购买前，把获得、使用、维护和退出连着想一遍：会用多久，谁能修，搬走或停服务麻不麻烦？转卖、转赠、回收和处理有什么条件与费用，也要查清。方便维修和退出的方案可能贵些，却更适合搬家或需求变化。

转售价只是估算，不能为将来卖高价买不需要的东西；已经按购入价减转售收入算总账，就不再加一次相同的转售损失。

移交设备前清理个人资料与账号绑定，说明已知故障和风险；不确定是否清理干净，就先核实。电池、电器和药品按当地适用要求处理，不自行拆危险部件，也不能把危险或处置责任偷偷转给别人。

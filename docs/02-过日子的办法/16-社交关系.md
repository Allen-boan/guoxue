# 2.16 社交关系

时间不只用来做事和学习，也用来与人相处。同样是花一个晚上，有时回来更累，有时觉得被理解、被支持。陪伴、信任和共同经历，都是生活品质，不能只看这一晚花了多少钱。

<a id="guide-relationship-quality"></a>

## 2.16.1 关系质量优于数量

群聊和应酬排满日程，却没空和重要的人认真相处，社交就可能同时挤掉休息和真正需要的支持。

回看最近的来往，分清哪些是彼此尊重的相处，哪些只是怕拒绝。给重要的人留出实际联系，把纯凑数的活动减少，说明时间与预算，也保留礼貌。认真维系仍要关心与沟通，不是把人排成收益榜，再只留下“有用”的几个。

缺少支持、感到孤立的人，反而可能需要更多联系。照护、工作和公共责任也不能一概当成浪费，减少无效应酬不等于断绝来往，更不代表别人没价值。

<a id="guide-no-conformity-spending"></a>

## 2.16.2 不为了合群消费

愿意相处，也不代表预算必须一样。朋友换新东西、聚会选贵地方，自己可以喜欢他们，却不想花这笔钱。

想想没有照片和比较时，自己还愿不愿意参加，这笔支出会不会挤压必要开销。说清能接受的预算，提出合适的替代；真喜欢又负担得起就参加，不适合就礼貌谢绝。共同体验、必要礼节或职业安排有实际意义，合理投入并不矛盾。

沟通可能费心，也可能错过一场喜欢的活动，但不必借债证明合群。预算不同不说明人格高低，自己不参加，也无须嘲笑朋友的选择或证明自己更高明。

<a id="guide-invest-important-relationships"></a>

## 2.16.3 重要关系值得投入

守住预算以后，还要留住关心。把见面、礼物和照顾都算成浪费，账单是小了，重要的人却可能一直等不到真实回应。

看看对方需要的是陪伴、倾听、帮助还是合适礼物，在能力范围内做一件具体的事。商量轻松的来往方式，照护负担重时一起讨论分担。花钱、费时、不那么方便，都可以是值得的投入，因为支持和相处本身就是收获。

昂贵礼物不能代替沟通，付出也不能用来控制对方、索要回报。尊重彼此意愿，保住基本生活与长期财务安全，不借债证明重视，也不必承受持续超出能力的单向付出。

# 2.9 物品使用与维护

东西带回家，买价就成了过去的账，接下来还有清洗、耗材、维修和收纳。真正好用的东西，既解决问题，也不让人每天围着它转。

<a id="ownership-total-cost"></a>

## 2.9.1 总拥有成本

比较家电、家具或设备时，可以先把预计使用期限内的钱算到一起：**购置价＋耗材、能源、维修等支出－保守预计的转售收入**。转售收入不确定，就少算一些；买价减转售收入已经包含转售损失，不再重复加一次。

钱之外，再看占多少空间、花多少时间照料，有没有安全风险。同一项只算一次，不必把所有时间折成统一时薪。比较满足需要的方案，既看长期负担，也看眼下现金流是否承受得住，用过以后再修正估计。

前期更贵，若能换来可靠、省心的长期使用，也可能值得。小额简单用品不必做复杂表格，紧急必需事项别为算账耽误；健康安全不能用便宜抵消。

<a id="ownership-low-maintenance"></a>

## 2.9.2 低维护优先

买价和使用效果接近时，后续照料就可能决定哪件更合适。买前看看怎么清洗，耗材多久换一次，配件是否好找，坏了找谁修。一个功能略少、却容易照料的选择，可能更适合普通日常。

省心的产品也可能买价更高。多付这笔钱是否值得，要看清洗和操心是不是真的减少，而核心体验仍然够用。留下必要保养安排，不能把“低维护”理解成从此不管。

医疗、无障碍、工作或重要兴趣确实需要复杂功能时，就保留这些功能。必要清洁、防护和安全检查不能省，耐用与否也要看具体产品，不能只信一个标签。

<a id="ownership-high-frequency"></a>

## 2.9.3 高频用品优先投入

弄清后续负担，再决定预算先改善什么。每天穿的鞋不合脚、坐的椅子不舒服，往往比低频展示品更值得处理。先找出持续出现的具体问题，试试调整和维护；确实解决不了，再比较合适的升级。

床、鞋或通勤工具可能需要较大的一次性投入，理由应是每天更舒服、顺手或可靠，而不是用得多就一定买最贵的。眼镜等专业需要，找可靠服务；买后没有实际改善，就不继续加价追配置。

现有物品已经够用，可以继续用。低频安全用品也可能必须保留，不能只凭次数淘汰；改善日常体验，不能透支必要生活费用和财务缓冲。

# 2.4 居住

身体要休息、吃饭和活动，住处就是承接这些需要的地方。家里舒不舒服，往往在普通的一天里最明显：起床有没有地方走，做饭顺不顺手，晚上能不能安静休息。[租房](08-消费购物.md#housing-rental-total)时要把这些需要考虑进去；已经住下来，也可以先从最常用的地方改善。

<a id="housing-high-use-spaces"></a>

## 2.4.1 高频空间优先

每天在昏暗的桌前工作，却先花钱装饰很少使用的角落，真正的不便还留在那里。回想一周，床、厨房、卫生间和工作位置，哪一处总让人费劲？先挑一个具体问题处理。

桌面太暗，可以调整位置或照明；厨房操作不顺，先清出操作面。能用现有东西解决，就不急着买。与同住的人确认需要，过几天再看是否更舒服、少了哪些折腾，没必要一次改完整个家。

改造要服从房屋条件和使用权限，不自行动有风险的电路、燃气或结构，不挡通道。照护、无障碍和共同生活的需要也要照顾到。已经好用的地方，不必为了统一风格重新花钱。

<a id="housing-useful-space"></a>

## 2.4.2 空间利用率

常用的地方顺手以后，再看空间有没有被无用占位挤走。面积大不一定好住，小空间也不能靠塞满收纳来解决。沿着睡觉、做饭、洗漱和工作时的路线走一遍，哪里需要侧身，哪里堆着长期不用的东西，通常就能找到堵点。

先挪已有家具、处理闲置，再决定是否添收纳或换房。比较房源时，看可用布局、采光和通风，而不只看面积单价；搬家和调整的支出，也要能换回实际便利。

够用包括活动和私密空间。儿童、照护、无障碍和居家工作有不同需要，不能追求越小越省。违法隔断、消防隐患或基本活动受限应排除，折叠家具也要牢固、好操作。

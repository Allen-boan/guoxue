# 2.6 家务与收纳

路上少些折腾，到家也想轻松一点。刚收拾好的家，过几天又乱了；东西藏得很整齐，需要时却找不到。家里的安排有没有用，最终要看住在里面的人是否方便，而不是照片是否好看。

<a id="guide-easy-cleaning"></a>

## 2.6.1 选择容易清洁的安排

沙发底下够不到，零件拆不开，台面总是留污迹，这些购买时不显眼的细节，会在每次打扫时重复出现。

添置物品前，看看接缝、底部、可拆洗结构和清洁说明，有没有特殊工具与耗材。对照旧物最难打扫的地方，确认新方案是否真能解决。现有东西能通过调整摆放改善，就先调整，不必为“好维护”全部换新。

易维护的物品可能贵一点，却能少做许多重复劳动；精细照料本就是乐趣，也可以保留。便利仍要兼顾用途与安全，按说明使用清洁用品，不随意混用，好清洁也不等于不用清洁。

<a id="guide-fewer-ornaments"></a>

## 2.6.2 少摆件

有时麻烦不在家具，而在台面上每次擦灰都要搬动的一排东西。真喜欢的摆件让家更舒服，早已不再欣赏的却只留下家务。

从一处常用台面开始，留下有纪念意义或经常欣赏的物品，其余先暂存。少了以后是否更自在，过一阵便能知道；确定不需要，再转赠或合理处理，比一时冲动全扔掉更稳妥。

美感和收藏本身就是收益，没有统一的数量标准，也不必又买一套摆件来追求风格整齐。家人的东西不能擅自处置，减少的是自己不再珍惜、却还在持续照料的负担。

<a id="guide-fixed-places"></a>

## 2.6.3 物品固定位置

台面腾出来了，常用品还得有个顺手的去处。不然钥匙、充电线和工具，依旧每天重新找一遍。

选三五样最容易找不到的东西，把位置安排在使用地点附近，和共用的人商量，必要时贴简单标签。总是放不回去，就调整位置或容器，让归位变得容易，而不是反复责备。少量合适的收纳工具，换来少寻找、少临时整理，也可能值得。

位置要照顾家人的身体条件，目的在于好拿好用，不是藏得彻底。药品、危险品和贵重物品按安全要求存放，紧急用品容易找到，公共物品遵守原有管理规则。

<a id="guide-sensible-stock"></a>

## 2.6.4 不过量囤货

位置安排好了，也经不住东西不断超量进入。大包装单价低，用不完或放过期，既占空间又占现金，还容易让人忘记已经买过什么。

下单前看一眼存量、消耗速度、保质期和储存条件，按家庭情况留一个好管理的余量，先用旧货。必要应急物资另记清楚，定期检查、轮换。采购不便或供应不稳定时，多留一点有实际作用，不必追求零库存。

少囤可能失去优惠、增加采购次数，要和释放的空间与预算一起比较。库存不能压到影响基本生活，也不能为清货勉强使用过期或储存不当的产品，食品和危险品仍按要求存放。

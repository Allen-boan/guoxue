# 2.2 睡眠

饭和水能安排妥当，休息却常被排到一天最后：等工作做完、家务收好、手机刷够，才轮到睡觉。第二天昏昏沉沉，又要花更多力气把同样的事做完。睡眠需要有自己的位置。

<a id="sleep-adequate"></a>

## 2.2.1 长睡眠理论：保障合理睡眠

合理睡眠没有适用于所有人的统一时长，也不是卧床越久越好。真正值得争取的是适合自己的休息机会，醒来后的状态能够支持正常生活。

白天被工作占满，夜里终于有自己的时间，舍不得结束并不难理解。可以保留真正喜欢的晚间活动，把无目的刷屏、反复拖延关机这些消耗先减掉。休息与娱乐不必互相挤到只剩一个，两者都需要实际的时间。

观察几天的入睡、起床和白天状态，通常能看出一些具体障碍。拖晚的是手机，就先调整使用；噪声一直打扰，就处理环境。轮班、育儿或照护家人时，缺的也许不是自律，而是排班调整、分工和他人的支持。

尽量规律地休息，给睡眠留出适合自己的时间，再看白天是否更有恢复感，精力与情绪是否改善。手环分数和卧床时长只能提供局部信息，不能证明睡得好，也不保证健康或减少医疗支出。

反复追逐时长和分数，如果增加焦虑，就应调整目标。持续失眠、明显嗜睡、睡很久仍异常疲惫，或睡觉时有明显呼吸异常，不应只靠“再睡久一点”处理；影响生活时，应寻求专业评估。不要自行用酒精或药物追求长睡眠，已有诊疗安排的按专业建议执行。睡眠不能替代疾病治疗，睡不好也不该被简单归咎为不够自律。

## 2.2.2 睡眠环境优先

给休息留出了时间，床边的噪声、刺眼光线或不合适的床具仍可能让人睡不舒服。先处理最明显的一项干扰，比一次买齐整套助眠装备更容易看出效果。

能用小调整解决的先调整；需要换床具，就看尺寸、实际体验和退换条件。每天都用得到、确实改善舒适度的东西，值得留出预算。更安静的住处可能贵一点，却比长期睡不好更合适。

用了仍无改善，就停下来重新找原因。环境不能解决所有睡眠问题，居住隐患和健康问题也须各自处理。遮光、降噪和取暖不能堵住通风或逃生路径，电器须安全使用；儿童等特殊人群按可靠专业要求安排。

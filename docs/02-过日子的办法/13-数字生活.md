# 2.13 数字生活

把通知收住以后，还有工具和服务本身的负担。手机里装满工具，账单上挂着会员，文件分散在几个云盘。它们原本为了方便生活，久了却也需要花时间管理。减少负担时，资料和必要访问能力不能一并丢掉。

<a id="guide-fewer-apps"></a>

## 2.13.1 减少重复 App

同一个任务装了几个软件，功能未必多用，账号、权限和通知却都增加了。

从一种任务开始，比较实际功能和权限，留下真正顺手的工具。确认替代方案能满足需要，迁移并核验资料以后，再停用重复软件；订阅、账号和登录方式也另查清楚，卸载并不等于取消续费或删除账号。

迁移与适应需要时间，集中到少数工具还要考虑服务中断和退出办法。必要的工作、照护和无障碍功能仍应保留，不为少装一个软件采用来源不明、权限过大的替代品，重要资料与访问方式确认后再删。

<a id="guide-subscription-audit"></a>

## 2.13.2 定期盘点数字订阅

软件停用了，费用可能还在扣；想取消云服务，又担心旧文件打不开。比起只看桌面上的图标，账单更能说明哪些服务还在付费。

从账单和订阅页核对价格、续费日期与实际用途。不用的可以取消，涉及云盘、邮箱和文档的，先查降级后的容量、访问和保留规则，迁移资料并验证完整、可打开，再取消，保存结果并检查后续账单。

盘点和迁移可能需要过渡费用，必要服务保留下来也有价值。资料未核验时，不贸然停止重要服务；删除 App 或支付方式未必取消成功，也不能假定服务会永久保留文件。

<a id="guide-data-backup"></a>

## 2.13.3 数据备份

文件迁出来，还不能只留在一台设备里。照片、作品和工作资料难以重建，一次故障、误删或账号问题，就可能让它们消失。

1. 把重要资料存到可靠位置，再留一份于独立设备或可信服务。同一硬盘的另一个文件夹，不是独立备份。
2. 确认能登录或解锁，妥善保存恢复方式，敏感资料按需要加密。
3. 定期把部分文件恢复到另一位置，检查完整、可打开，并按更新频率补备份。

存储和检查要花钱与时间，保护的却是记忆、作品和工作。同步可能把误删一起同步，不能自动当作备份，应确认独立副本或可恢复历史。

清空设备、删除原件或取消服务前，还要验证所需资料完整并且能恢复。备份不能保证零损失，也不能把敏感资料交给陌生服务；能存进去不够，能取出来才有用。

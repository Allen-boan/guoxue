# 2.1 饮食

饭要天天吃，真正影响生活的，往往是平常那些不太起眼的一餐。吃得合适、干净、合口味，比给食物贴上多少“精致”“健康”的标签更实在。

<a id="food-basics"></a>

## 2.1.1 基础饮食优先

正餐总是凑合，却买了不少昂贵的“健康食品”，钱可能绕开了最需要它的地方。先看看常吃的几顿饭：主食、蛋白质食物、蔬菜水果有没有各自的位置，哪个缺口最明显，就先补哪个。

不必每天重新设计菜单。留下几种买得到、做得来、吃得惯的搭配，忙的时候也有可靠的选择。外食同样先看吃到了什么，再看店名和宣传。保健品不能替代正常吃饭。

省钱不能靠长期吃不够、单一饮食或不安全的食物。食物过敏、孕期和疾病相关的饮食需要，应按自己的情况及可靠专业建议安排。

<a id="food-daily-and-experience"></a>

## 2.1.2 日常饭与体验饭分开

吃得可靠，不意味着每顿都要精心制作；吃得简单，也不意味着放弃口味和快乐。工作日有几个省心、合口味的选项，就能少花一些选餐和备餐的精力。

真想吃的一顿，可以留出预算和时间好好享受。喜欢的味道、与重要的人相聚，都是这顿饭的实际价值。吃完觉得值得，下次再去；如果只剩拍照和赶场的疲惫，就不必为了“应该去过”再付一次钱。

日常饭负责稳定，体验饭带来乐趣，两者不必使用同一个价格标准。也别为攒一顿大餐，长期亏待平常的饭。

<a id="food-less-packaging"></a>

## 2.1.3 少为包装买单

决定吃什么之后，再看差价买到了什么。更好的食材、可靠的保鲜、方便携带的分装，可能确实有用；联名标签和礼盒，也可能只是让同样的食物贵了一截。

比较同类食品时，按能吃到的量算价格，同时想想自己能否吃完、如何保存。大包装单价低，放坏了一半，就未必更便宜。喜欢设计可以为它付费，只要知道自己买的是这份喜欢。

散装卫生无法确认，或需要特殊配方时，合适的完整包装更重要。过期、破损、信息不清或储存不当的食品，再便宜也不值得冒险。差价很小时，也不必为了比较耗掉整个晚上。

<a id="food-water"></a>

## 2.1.4 大水理论：把日常饮水安排顺手

饭吃得稳定了，日常喝水也可以少一点折腾。常忘带杯子、接水麻烦、出门只能临时买饮料，问题未必在自制力上，也可能是喝到水太不方便。

“大水理论”的作者是**长安二球（大水教父）· `@TangSMer`**，其完整主张待补充。作者写道：

> 我的大水理论火遍全网
>
> 又有几个人能看出抽象之下的健康内核？

具体到生活，先找到饮水最不顺手的场景。桌边放一个好清洗的杯子，出门前装好水，提前确认可靠补水点，往往比再添一套设备更有用。已经有合适的容器，就可以先用起来。

大瓶能少接几次水，也可能太重、漏水、难洗；净水设备除了买价，还有耗材和清洁。要比较的是整个安排是否方便、可靠，而不是瓶子有多大。水源须安全，容器须及时清洗；按当地供水提示处理，烧开不能解决所有污染问题。

如果自备水替代了常喝的高糖饮料，可能有健康益处，但不能推导成喝得越多越好。喜欢一杯饮料的味道，也可以为它花钱。

饮水需要随身体、环境和活动变化，不设人人相同的固定量。不要强迫短时间大量饮水，也不要用水替代吃饭或治疗。有液体摄入限制时遵从医嘱，高温劳动、剧烈运动等情形需要另外安排。强迫饮水后出现不适，应停止；明显或持续不适，应及时寻求医疗帮助。

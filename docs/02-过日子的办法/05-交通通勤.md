# 2.5 交通通勤

住得合适，还要把出门和回家的这段路算进去。路上的时间也是日子的一部分。每天在路上待多久，到家还有没有力气，都属于出行体验。选交通方式，不只是找最低车费，也要把时间、疲劳和安全放进来。

<a id="commute-time-cost"></a>

## 2.5.1 通勤时间也是成本

地图上四十分钟的路线，算上走到车站、等车和换乘，可能远不止四十分钟。按普通上下班时段试走，记门到门时间、常见延误和到家后的疲劳，比只看线路长度更有用。

往返时间占掉了哪些事，也值得具体看一看：晚饭、睡眠、陪伴，还是原本想做的运动？再把交通费和居住体验并排比较，按预算和照护责任选择能长期承受的安排。不必统一给时间标价，离公司最近也不一定最好。

暂时搬不了，可以先改善换乘、等车或最后一段路。住得近与搬家可能更贵，预算有限也不能拿明显不安全的路线或房屋交换。

<a id="effective-transport"></a>

## 2.5.2 最短有效交通

同一段路，工作日、雨天、带孩子时，合适的走法可能不同。比较两三种方案的完整时间、费用、换乘、天气和体力要求，实际试过，再留一条常用路线和可靠备选，不必让一种工具包办所有出行。

必要时打车、停车或买合适装备，可以换来省力和安全；自有车辆还有保养、停放与退出负担。工具值不值，在于这趟路能否走得顺，而不在于它代表什么身份。

行动不便、夜间和恶劣天气要重新评估。遵守交通规则，头盔与必要防护不省，不为赶时间冒险。“最短有效”也不是争最快速度。

<a id="local-life-circle"></a>

## 2.5.3 15 分钟生活圈

通勤以外，买菜、取件和运动也会占掉不少路程。标出一周真会用到的地方，看看哪些可以顺路完成，哪些附近已有合适替代。找住处时，同样要实地看看配套价格、质量和可达性，地图上有店不等于可靠。

便利地段可能有溢价，是否值得，要看使用频率和实际减少的跑腿负担。附近办好常见小事，是为了日常轻松一些，不是把生活限制在一个圈里。

“15 分钟”只是容易理解的目标。偏远地区、轮班和特殊照护未必能短距离解决，必要医疗、工作和重要关系的可达性，也不能为了凑这个数字舍弃。

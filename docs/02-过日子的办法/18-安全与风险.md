# 2.18 安全与风险

旅行要顾着交通和活动的安全，日常也要留住必要的防护。备用物资、防护和保障，平时可能很少用到。但意外真来了，有没有退路，影响的往往是基本生活，而不是少花了多少钱。

<a id="guide-safety-reserve"></a>

## 2.18.1 安全冗余

刚好够用的安排很省事，遇到停供、故障或资料丢失，却可能一下失去支撑。必要余量的价值，在于事情出错时仍有办法应对。

按家庭情况找出后果严重、现实可防的风险，补上最关键的退路：必要应急物资、能恢复的资料备份或合适保障。检查有效期和可用性，让家人知道怎样使用；保险则读清保障范围、除外责任和持续费用，不能以为买了就什么都覆盖。

备用安排占钱、占空间，也需要维护，数量按实际风险决定，不靠不断购物缓解焦虑。它不能保证零风险，更不能替代安全习惯，基本生活预算也要留住。

<a id="guide-essential-protection"></a>

## 2.18.2 不省必要防护的钱

有退路，还要尽量避免伤害发生。头盔、防护用品和电器只比较售价，忽略适配、合规或损伤，省下的钱可能换来不可逆的后果。

按活动和当地适用要求确认需求，从可核查渠道选择合格、用途与尺寸合适的产品。照说明佩戴或安装，定期检查磨损、损坏和更换条件。现有产品仍合格适用，无须为身份标签升级；贵不自动合格，便宜也不自动危险。

普通用品不能冒充专业防护，有损伤史不能只靠外观判断。不确定是否可靠，就停止依赖并核实。防护是减少风险的措施，不是冒险许可，环境和使用方式仍要注意。

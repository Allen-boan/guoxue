# 2.11 时间管理

少些需要反复操心的物品，已经能腾出一些时间。让运动、休息和重要的人有位置，不一定靠把日程排得更满。有些时间可以从重复折腾里拿回来，也可以留给发呆和兴趣，不必每一分钟都证明自己有产出。

<a id="time-value"></a>

## 2.11.1 把时间成本算进去

为一个小价差反复领券、跑店和刷新，省下多少钱容易看到，耗掉的下午却容易忽略。试着估计额外操作用时和实际节省，别把满减金额都当净收益，再看休息、工作或陪伴有没有被挤走。

少数方便又有效的省钱办法可以留下，收益小、太麻烦的可以换安排。付费省时能换回选择余地；现金紧、时间宽裕，或确实喜欢研究和动手时，花时间省钱也可能适合。

不按工资给所有闲暇统一定价，也不把休息当浪费。赶时间不能省掉必要验货、安全检查和专业判断，钱与时间哪种更紧，要按实际生活取舍。

<a id="batch-tasks"></a>

## 2.11.2 批量处理

减少反复启动，往往比做得更快容易。一天里多次采购、洗一点衣物或缴一笔账单，事情很小，却不停打断手头的事。先选一类时间要求相近的任务，把采购、账单检查或简单家务适当合并。

按用量和处理能力安排，不为了“集中做”大量囤货，也不把一天塞满。看看合并后是否更轻松；需要及时完成或容易拖延的事，分次反而可靠。节省出门与准备的同时，也要留意整段时间和储存空间够不够。

食品按可靠的保鲜、卫生要求处理，账单不等到批量日逾期。截止期不同、照护需求难预测或储存不足，就不硬凑一批。

<a id="default-options"></a>

## 2.11.3 默认方案

除了合并任务，有些重复选择也不用从零开始。早餐、穿搭和日用品已有满意答案，可以留下两三个预算能承受的选项，记下来或放在顺手位置，普通日子先用它们，想换口味再另选。

第一次筛选仍要花时间，之后省的是重复比较，不是新体验。价格、身体或生活条件变化时，重新确认；默认方案可以调整，不必坚持到它已经不好用。

默认不等于只吃一种饭、只穿同一套衣服，更不意味着囤货。特殊饮食、工作要求和新风险出现时，要重新判断，产品规格变化也不能照旧盲目复购。

<a id="practical-automation"></a>

## 2.11.4 合理自动化

规则清楚、反复发生的事，还可以交给现有工具：简单提醒、固定清单，或合适的自动支付。先从一件事试起，看看是否少了遗漏与惦记，而不是为了用工具新增一堆维护。

自动支付前确认金额、周期、余额、取消方式和提醒，只给必要权限。设置和软件可能花钱，后续也要维护；保留账单检查、异常提醒与手动办法，实际比原任务更费心就停用。

金额变化大、容易误付或需要个人判断的事，不直接全自动。续费仍受预算约束，不随意上传敏感资料或共享密码；重要流程保留备选，不能因为“自动了”就永远不看。

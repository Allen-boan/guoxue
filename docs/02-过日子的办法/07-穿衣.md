# 2.7 穿衣

衣柜也是每天要用的一块空间。早上打开衣柜，能找到合身、舒服、适合今天的衣服，就已经解决了穿衣的大部分问题。喜欢漂亮衣服当然可以；困扰常常不是买得不够，而是买了不少，却很少真正穿上。

<a id="clothing-fewer-useful"></a>

## 2.7.1 少而好穿

先看最近常穿的几件：为什么愿意穿它们，是合身、好搭，还是清洗方便？下次补衣服，就从这些真实感受出发，按气候、工作和洗衣频率找缺口，不必按别人规定的件数清衣柜。

试穿时坐下、抬手、走几步，确认动作舒服，再想已有的衣服能否搭配。重复款可以暂缓，不合适的按状态修补、转让或处理。衣服少一点，是为了少留闲置；审美带来的快乐也有价值，不必只剩功能。

专业防护、制服、特殊体型和身体需要要先满足，保暖、防晒不能为了少买而缺失。数量够不够，由自己的生活决定。

<a id="clothing-cost-per-wear"></a>

## 2.7.2 单位穿着成本

两件衣服都合适，价格不同，可以再想想实际会穿多少次。打折后只穿一次，未必比常穿的那件划算。用买价除以保守估计的穿着次数，是一个辅助比较办法，别拿“以后天天穿”替自己算账。

次数之外，还要看清洗、修补、舒适和场合需要。穿过一段时间回头看看，预计是否接近实际，下一次就更容易选准。更高的买价要有真实用途支撑，不能为了“长期划算”负债。

不舒服的衣服，不值得为了摊薄成本硬穿。专业防护或少见但必要的礼仪用衣，也不能仅凭穿得少就认定不值。

<a id="clothing-standard-basics"></a>

## 2.7.3 基础用品标准化

有些选择一旦满意，就不用每次重新研究。袜子或内衣已经穿着舒服，可以记下型号、尺寸和感受，下次需要更换时先看原款；第一次只试少量，别为统一一次买满。

复购前仍要确认材质、规格有没有变化，数量按使用和洗衣频率补足。省下的是重复比较的工夫，不是把所有衣服变成同一种样子。身体、气候或需要变了，原来的选择也可以换。

固定一个好用的选项，不等于囤货或忍受不合适。优惠再大，也没有必要买超过实际用量的库存；喜欢尝试新款时，同样可以给新体验留位置。

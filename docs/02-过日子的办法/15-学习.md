# 2.15 学习

工作里需要补能力，生活里也总有想学会的事情。资料收藏了很多，遇到事情还是不会做；也有人只学会一项小技能，就解决了天天困扰自己的问题。学习的收获，和材料堆得多高并不总是一回事。

<a id="problem-led-learning"></a>

## 2.15.1 问题驱动学习

“全面提升自己”很难下手，“看懂这份账单”或“做出一个能用的表格”就具体得多。事情做不做得成，也能告诉自己哪里还没学会。

选一份适合基础的可靠材料，带着这个问题边学边做。碰到关键概念不懂，就补基础；做完再看还有什么缺口。这样能减少来回换课和重复付费，却不意味着系统知识可以省掉。

长期教育和专业训练仍需要完整学习，健康、安全、法律和职业资格相关任务，做对一次也不代表已经掌握。纯兴趣学习同样有价值，理解与享受就是收获，不必强行变现。

<a id="practice-before-courses"></a>

## 2.15.2 输出优于囤课

问题明确了，材料也有了，最容易拖延的反而是动手。再买一套课很轻松，做一次练习却会暴露自己哪里不会。

从已有且可靠的材料里选一份，学一小段，就做练习、用自己的话解释，或者完成一个小作品。卡住的地方才是需要补材料、找反馈的地方，不必每次从购买开始。旧资料错误、过时或缺少基础，就换可靠材料，也不用为了“用完”继续受误导。

作品可以只给自己看，阅读、思考和休息也是学习的一部分。公开时尊重版权与隐私，专业结果仍要核验；展示频率不能代替真正理解。

<a id="fit-for-purpose-learning"></a>

## 2.15.3 80% 够用：普通技能先能解决问题

动手以后，又可能因为做得不够漂亮迟迟不肯用。整理资料、基础做饭和普通工具操作，往往不需要等到专家水平才开始改善生活。

把“能用”定清楚：在当前场景里，能否可靠地完成任务？学好必要基础，做一次可检查的小任务，认识常见错误；够用就先使用，遇到新需求再深入。少一些不必要的打磨，启动也就容易一些；喜欢这件事，当然可以继续精进。

“80%”是比喻，不是允许错两成。医疗、安全、法律、职业资质和容错低的任务不能降低要求，不清楚关键风险时应先核实或求助。

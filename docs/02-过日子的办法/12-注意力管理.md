# 2.12 注意力管理

时间留出来了，也可能不知不觉被打断。打开手机查一条信息，回过神已经刷了半小时。时间过去了，原本要做的事却没动。要减少这种消耗，先看看注意力是从哪里被带走的。

<a id="attention-is-cost"></a>

## 2.12.1 注意力也是成本

免费应用不一定没有代价。推荐、签到和广告如果总让人偏离目的，就会占用时间，也可能带来原本没有的焦虑和消费。

观察几天，找出最容易把自己带走的入口，试着关掉推荐、直接搜索，或收藏常用页面。已有工具能解决，就不急着换；收费工具确实少打扰、用得顺手，也可以值得付费，但要连同价格、权限和迁移难度一起考虑。

工作、照护和无障碍功能仍要保留，迁移前保护好账号与资料。主动选择的娱乐有自己的价值，判断的是自己是否愿意这样花时间，不是每分钟有没有产出。

<a id="essential-notifications"></a>

## 2.12.2 少通知

入口收住了，提示音还可能不断把人拉回来。促销响一下、群聊亮一下，正在做的事就得重新接上。

把促销、推荐和无关群提醒关掉，保留重要联系人、必要工作消息和安全警报。非紧急消息放到方便的时段看，再检查有没有漏掉账单或照护信息。让重要的人知道紧急时怎样联系，比一边全静音、一边担心漏消息更踏实。

值班、照护和紧急响应需要随时可达，不能套用统一规则。减少通知是让真正重要的消息更容易被看见，也让其余时间少一点打断。

<a id="information-diet"></a>

## 2.12.3 信息饮食

安静下来以后，仍可能看了很多观点，眼前的问题却没有进展。消息少了，不代表留下的内容就有用。

把正在处理的两三个问题写清楚，围绕它们找可靠信息；重复资讯、持续制造焦虑的账号，可以少看。健康、安全和重要决定尤其要核对出处，看看不同证据是否支持同一个判断，不能只留下顺耳的话。

兴趣阅读、研究和创作也需要漫游，暂时用不上的知识不必全部删掉。筛选是减少无关的消耗，给真正想了解的事留空间，不是把阅读变成必须交成绩的任务。

<a id="research-stop"></a>

## 2.12.4 信息搜集止损

即使信息有用，也会出现另一种停不下来：已经找到合适的东西，还开着几十个标签页，想保证自己绝没有买亏。

普通低风险选择，可以先明确功能、预算、风险检查和退换条件。找到合格方案，后面只剩重复评论和小价差，就可以结束比较；新证据会改变关键判断时，再继续查。少拿一点优惠，换回时间和心思，也可能划算。

预算紧、缺少经验或研究本身就是兴趣，多比较一阵有它的理由。医疗、安全、合同、重大财务选择和难以验货的商品，则必须完成必要核查，不能拿“别纠结了”催自己草率决定。

# 2.17 旅行与娱乐

相处可以是在家吃饭，也可以是一趟旅行。难得出去玩，最想要的是休息、探索，还是和人好好相处？先认清这次期待的体验，行程和预算才有依据，不必让打卡数量替自己作主。

<a id="guide-travel-not-checklist"></a>

## 2.17.1 旅行不是打卡竞赛

景点排得满，赶路和排队也排得满，回来可能比出发前还累。去过很多地方，不一定真的享受了这趟旅行。

和同行者各选最想体验的事，核对体力、兴趣和预算，按交通与休息需要留出余地。很远又没那么想去的项目，可以删掉；已经买了门票，也不必因此硬撑。地方少去一些，喜欢的体验花得多一些，仍可能更值得。

喜欢密集探索当然可以保留自己的节奏，也尊重同行者的偏好。留白不等于省掉准备，交通、营业、预约、住宿和安全时间窗口仍要确认，团队约定也应遵守。

<a id="guide-off-peak-leisure"></a>

## 2.17.2 淡季错峰

行程不再追求塞满，如果时间还有弹性，就能比较不同日期。但一张便宜机票，不足以说明整趟旅行更省、更好玩。

把交通、住宿和活动的实际总价放在一起，确认想要的体验是否照常开放；天气、交通和安全限制，也得查清。和同行者算上请假、照护以及退改代价，再决定日期。若这些成本高，或者核心体验在淡季消失，旺季也可能更合适。

错峰有机会少等待、少开销，却不能保证一定便宜、人少。停业、交通减少、恶劣天气和不可退费用都可能改变结果，安全与必要服务不能靠折扣补偿。

<a id="guide-entertainment-hour-cost"></a>

## 2.17.3 每小时娱乐成本

平日里的娱乐也有类似问题：游戏、会员和设备买了不少，真正喜欢、经常使用的却只有几项。

用同一时期的实际支出除以实际娱乐小时数，粗看哪些开销长期闲置；没用过就记为未使用，不必硬算。再问自己好不好玩、是否珍惜，有没有挤掉睡眠和必要事务，优先调整不用或不享受的部分。

这个数适合辅助比较相近选择，不能给一场演出、一段陪伴或珍贵旅行定价。短暂体验也可以很值得，不为摊薄价格强迫多玩，也不让低单价掩盖沉迷与健康问题。快乐不是按小时排的榜单。

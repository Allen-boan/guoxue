# 第二章｜过日子的办法

一顿饭总在纠结吃什么，一件东西总在找放在哪里，晚上想早点睡，手机却迟迟放不下。这些事单独看都不大，天天叠在一起，就会占掉不少时间和心力。

吃饭和休息照顾身体，住处和出行影响舒适与便利，买回来的东西也带着后续负担。这些安排连着有限的钱、时间和心力；少些无效消耗，工作、关系和喜欢的生活才有余地。

# “过学”到底在优化什么？

[返回全书目录](../README.md) · [“过学”总纲](02-过学总纲.md)

> **生活成本可以低，生活品质不能低。**
>
> 成本不只是钱。品质也不是买得贵。
>
> 我们研究的不是怎么把日子过便宜，
> 而是怎么用更低的综合成本，把日子过得更好。

## 一张图的事，用三句话讲清楚

> **少付无效成本**
>
> 钱、时间、精力、注意力、维护、空间、决策、情绪负担、机会和长期风险。
>
> ↓
>
> **把资源留给真正重要的事**
>
> 健康、睡眠、营养、舒适、安全、便利、自己的时间、好的情绪、重要关系、真实体验、稳定与长期可持续。
>
> ↓
>
> **更低的综合生活成本 + 更高的真实生活品质。**

这里的“少付”是减少无效消耗。必要医疗、合理营养、安全防护和重要关系，不在清除名单里。

## 什么是生活成本

**综合生活成本，是一项选择从开始、使用到退出，让你实际付出的各种资源与承担的后果。**

为了好读，这里把健康与安全放在一类；记录规则时，它们分开看。

| 成本 | 生活里怎么出现 |
| --- | --- |
| **金钱** | 购买、房租、交通、吃饭、服务、维修、耗材、订阅等直接支出。买时少付，不等于后面少付。 |
| **时间** | 通勤、排队、比价、研究、清洁、维护、处理琐事。自己花的时间也有代价。 |
| **精力** | 体力与脑力投入，以及折腾、协调、沟通、反复处理问题的负担。 |
| **注意力** | 通知、营销、过度研究，以及需要反复惦记的物品和服务。免费软件也可能在占用它。 |
| **维护** | 为了继续正常使用，要做的保养、维修、清洁、升级、换耗材、续费和管理。它是一组持续负担，不是额外重复加一笔钱。 |
| **空间** | 物品占用的居住、收纳空间，以及搬家时的负担。它放在家里，也在占用你的生活。 |
| **决策** | 每天重复决定早餐、穿搭、牌子和购买方案。小事反复重选，也会累。 |
| **情绪** | 攀比、焦虑、人设、无效社交、消费后悔与长期操心。真正喜欢的爱好，不因需要投入就自动算内耗。 |
| **机会** | 选了这一项，就无法把同样的钱、时间和精力用于其他事情。看被挤掉的选择是否更重要。 |
| **健康与安全** | 一时便宜却带来的身体损伤、睡眠不足、营养问题或事故风险，也可能增加未来医疗和生活负担。它们首先是底线问题。 |

**不要把这些栏目当成可以直接相加的十一张账单。**

一次维修付了 100 元、花了半小时，可以分别记录金钱与时间；“维修”是说明这两项为何发生，不能再凭空加 100 元维护费。同一次比价造成的注意力和决策负担，也不该在一个总分里反复加权。

机会成本用来提醒“我放弃了什么”，不再把已经记录过的付款重复算一次。风险是可能后果，要说明已知、未知与依据，不能把猜测当成已经发生的损失。

## 什么是生活品质

**生活品质，不是你拥有的东西有多贵，而是你每天真实的生活体验有多好。**

| 品质 | 看什么 |
| --- | --- |
| **健康** | 身体和精神状态、体能，以及长期健康风险。无需靠外观统一评判。 |
| **睡眠** | 是否有适合自己的合理睡眠、睡眠质量与恢复体验。长不等于一定好。 |
| **营养** | 基本营养能否稳定满足，饮食是否适合自己。吃饭的愉悦，也可以记在真实体验里。 |
| **舒适** | 温度、噪音、卫生、床、衣物、座椅与空间，是否让每天过得舒服。 |
| **安全** | 身体、居住、交通、财产、交易与数据安全。不能靠赌“应该没事”换便宜。 |
| **便利** | 买菜、做饭、通勤、办事是否顺手，是否减少无意义折腾。 |
| **时间自主** | 有多少真正由自己安排的时间，不是每一刻都被任务和提醒牵走。 |
| **情绪状态** | 是否更轻松、稳定，减少焦虑与操心。它不代替需要的心理或医疗支持。 |
| **重要关系** | 与家人、伴侣、朋友及其他重要的人，是否能保持真实联系、照顾与合理责任。 |
| **真实体验** | 兴趣、娱乐、旅行、运动与日常快乐。对自己有价值，不必适合展示。 |
| **稳定性** | 突发支出、设备故障或安排变化后，生活是否仍有余地，而非一点问题就全线失衡。 |
| **长期可持续** | 身体、预算、精力和责任是否允许这套安排长期维持，而非短期硬撑。 |

这些方面会交叉。安静的房间可能同时改善舒适和睡眠，备份可能同时保护安全和稳定。分别说明帮助理解，不代表获得两个“加分”就能抵消别处的损害。

## 少一些负担，换回哪些真正的品质

### 少买不需要的饮料 → 把喝水安排得安全、方便

**可能减少：**饮料支出、采购与选择负担。  
**要保住：**安全饮水、个人健康与日常便利。  
**别漏算：**取水、携带和容器清洁。大水不等于统一要求所有人多喝。

[大水理论](04-过日子的具体方法/01-大水理论.md) · [饮食行动](行为指南/01-饮食.md)

### 少熬无意义的夜 → 给合理睡眠留时间

**可能减少：**疲劳、反复补救的精力负担。  
**要保住：**合理睡眠、恢复和日间状态。  
**实际投入：**需要把一部分时间从其他安排中留出来，效果因人而异，不能保证提效或替代医疗。

[长睡眠理论](04-过日子的具体方法/02-长睡眠理论.md) · [睡眠行动](行为指南/02-睡眠.md)

### 少付无效房租溢价 → 住得安全、安静、通勤可承受

**可能减少：**租金和展示性支出。  
**要保住：**安全、睡眠、舒适与时间自主。  
**别漏算：**交通、搬家、噪音、能源费用和合同责任。租金少 500 元、每天多两小时通勤，只是一个提醒算总账的例子。

[租万物里的租房](04-过日子的具体方法/租万物/01-租房.md) · [居住行动](行为指南/03-居住.md)

### 少买只为拥有的新品 → 把钱留给实际使用

**可能减少：**购买价格、闲置与空间负担。  
**要保住：**功能、安全、便利与真实体验。  
**别漏算：**二手筛选、验货、清洁、维修和售后；租赁还要看归还与赔偿责任。买新、买二手或租，都有可能合理。

[二手消费](04-过日子的具体方法/04-二手消费.md) · [租万物](04-过日子的具体方法/05-租万物.md) · [购物行动](行为指南/05-消费购物.md)

### 多花一点合理运动成本 → 换适合自己的功能与体验

**可能增加：**时间、会员费、装备与维护。  
**可能改善：**身体功能、健康、兴趣体验与可持续性。  
**判断条件：**方式适合身体、预算可承受、能坚持，收益有实际依据。不是越贵越有效，也不是所有人都要练成同一种身材。

[薄肌理论](04-过日子的具体方法/03-薄肌理论.md) · [健康与运动行动](行为指南/08-健康与运动.md)

## 遇到新办法，先填这五行

> **我想解决：**一个具体问题。  
> **少付的成本：**哪些负担确实减少？  
> **新增的代价：**钱、时间、维护与退出，谁承担？  
> **品质变化：**保住什么、改善什么、损失什么？  
> **条件与未知：**适合谁，哪些事实还要核查？

然后先查健康、安全等底线，再用[十条基本原则](03-十条基本原则.md)比较选择。

不用给每种成本标价，也不用把生活做成表格比赛。能把代价与体验说清楚，就已经比只看价格多走了一步。

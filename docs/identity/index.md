# 你是不是过的人？

**没有考试。看哪几句像你。**

<div class="identity-sheet">

## 过的人 · 日常对照清单

- 买东西先考虑使用价值。
- 不喜欢为了面子花钱。
- 愿意在真正重要的地方花钱。
- 觉得睡眠比熬夜装忙重要。
- 更在乎房子舒服，而不是看起来贵。
- 能接受合适、可靠的二手物品。
- 不追求无意义升级。
- 不喜欢维护复杂的人设。

**你可能早就是过的人，只是以前没人给它起名字。**

生活成本可以低，生活品质不能低。

这张清单可以截图分享。它没有合格线，也不会按你买了什么、花了多少钱来颁发身份。

## 认同这个名字，需要做什么？

不用买课、买装备，也不用完成一套生活改造。

先想一件小事：**我现在付出的某种成本，真的换来了我在乎的东西吗？**

如果答案是没有，找个可承受的方式调整。如果答案是有，就安心把它留在生活里。

## 还有两句，要一起认同

愿意省无效的钱，也愿意守住健康、安全和重要关系。

能说“这个办法适合我”，也能接受“别人不必和我一样”。

**混的人混社会，我们过日子。**

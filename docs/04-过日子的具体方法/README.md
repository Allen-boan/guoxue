# 第四章 · 过日子的具体方法

**“过学”讲判断，具体方法讲怎么做。**

这一章先分成五个大项，不要求你全用上。先挑一个眼下想解决的问题，再看这个方法能不能让日子更好过。方法可以不同，判断的原则要清楚。

## 挑一件事，从这里开始

| 眼下的问题 | 阅读哪一篇 | 先看什么 |
| --- | --- | --- |
| 喝水麻烦，总顺手买饮料 | [01 · 大水理论](01-大水理论.md) | 安全、方便的日常饮水 |
| 睡觉总给工作、刷手机让路 | [02 · 长睡眠理论](02-长睡眠理论.md) | 给合理睡眠留出时间和条件 |
| 想动起来，又不想被身材焦虑绑住 | [03 · 薄肌理论](03-薄肌理论.md) | 训练反馈、个人目标与健康边界 |
| 有需要，但不一定要买全新的 | [04 · 二手消费](04-二手消费.md) | 使用价值、成色与交易风险 |

### 租万物，按生活场景往下读

租房、租工具、租出行或活动用品、租短期设备、租阶段性家具，都放在“租万物”这一项里。

目前先展开[租房篇](租万物/01-租房.md)：房租、居住体验、通勤和安全一起算。其他场景先在[租万物](05-租万物.md)中比较，不急着拆成更多独立篇目。

租房可能每天都用，租工具可能一年只用几次。频率不同，不影响它们同属租用场景；是否值得租，要按自己的需要和完整成本判断。

## 每篇怎么读

各大项和展开的子篇采用相同的十问：是什么、解决什么问题、为什么吸引人、哪里有价值、怎样符合“过学”、对应哪些原则、怎么实践、何时不适合、有什么边界、在本书中怎么使用。

如果只想先动手，可以直接看第 7 问；做之前，再读第 8、9 问。别把最重要的限制跳过去。

目前五个大项中，薄肌、二手消费、租万物三项为**有条件收录**；大水、长睡眠两项为**观察中**。租房是租万物下面的实践子篇，保留有条件收录的判断，不另算一个大项。收录针对文中写明的做法和边界，不要求照搬一个名称下的所有说法。

## 实践前，先问自己三件事

1. **我真的有这个问题吗？** 别为了加入一个理论，先给自己制造需求。
2. **省下什么，又付出什么？** 多花一小时、少睡一觉、承担安全风险，都有成本。
3. **它能在我的生活里持续吗？** 身体、收入、家庭和工作不同，答案可以不同。

选一件事，小范围试试。没有改善就调整，没有必要就不做。过日子不用交一份满分答卷。

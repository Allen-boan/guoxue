# 04 · 二手消费

**东西是给自己用的，不是给包装盒争口气的。**

当前状态：**有条件收录**。前提是需求真实、成色可靠、风险可接受。

来源类型：已有网络实践。

作者与原始来源待补充。

## 1. 这是什么

有真实需求时，把成色可靠、来源可核验、总成本合适的二手物品纳入选择，而不是默认“不是全新就不能用”。

“咸鱼买东西”是常见口语表达，一般指闲鱼等二手交易渠道。

二手也不是天然划算。缺少保障、难辨损坏或修起来很贵的物品，低标价可能只是风险的前半段。

## 2. 它解决什么现实问题

有些东西买来使用不多，功能却仍能满足别人。二手选择有机会减少全新溢价；处理闲置，也能减少收纳和维护负担。

它解决的是部分购买与闲置问题，不是让人因为“捡漏”买更多东西。

## 3. 为什么会吸引人

低标价、可见的物品状态和人与人直接交易，会让人愿意多比较一种选择。但不同品类、成色和保障差别很大，二手不保证更便宜，也不保证一样好用。

## 4. 最有价值的部分是什么

把“新不新”和“好不好用”分开。一本书、一张尺寸合适且状态可靠的桌子，可能不需要全新才能发挥价值。

同时学会停手：真正的省钱，是买需要的东西。没有需求的半价，仍是一次完整的支出。

## 5. 怎样符合“过学”

如果使用体验没有明显损失，又省掉新货溢价，二手可以符合“过学”。比较时必须算上运费、清洁、维修、检验、售后，以及寻找过程花掉的时间。

贵一点但保障更明确的全新商品，也可能是更合理的选择。

### 用成本与品质看这件事

| 先问什么 | 二手购买怎么判断 |
| --- | --- |
| 可能省下什么 | 减少购买支出和不影响功能的新货溢价；处理闲置还可能释放空间。 |
| 可能增加什么 | 找货、沟通、验货占用时间、精力和注意力；运费、清洁、维修与售后缺口可能抬高总成本。 |
| 保住或改善什么 | 保住需要的功能、便利、卫生与安全；可靠、合用的物品才有真实使用价值。 |
| 怎样判断值不值 | 同用途比较完整费用、可验证状态和保障。只省标价，却长期维修、担心或不能安全使用，就不能说划算。 |

按[成本—品质框架](../成本与品质.md)，安全隐患不能用低价抵消，验货的时间也不能假装免费。

## 6. 对应哪些基本原则

- **P02 去无效溢价：** 不默认为“全新”标签付费。
- **P03 核心需求优先：** 先确认需求，再看折扣。
- **P06 长期成本：** 成色、维修与售后进入同一张账。
- **P07 真实使用价值与高频优先原则：** 按功能、实际状态和预计使用频率判断。
- **P08 因人而异：** 每个人可接受的风险和时间投入不同。
- **P10 不为别人眼里的体面买单：** 二手不影响东西把事做好。

完整说明见 [第三章：十条基本原则](../03-十条基本原则.md)。

## 7. 普通人怎么实践

1. 先写好用途、尺寸和必须具备的功能，设一个总预算。
2. 对照可靠的新货价格，加入运费、清洁和可预见的维修成本。
3. 向卖方确认真实照片、缺陷、使用历史、配件和可核验的购买信息；聊天承诺留记录。
4. 了解渠道的付款、验货、退货和争议规则，谨慎对待催促转账、异常低价与绕开保障的交易。
5. 电子设备按品类检查功能、账户锁和数据情况；收货后先验，再按规则确认交易。
6. 出售个人设备前，备份并安全清除数据、解除账户绑定；分享照片和寄件信息时注意地址与隐私。

家具还要考虑搬运、卫生与虫害。价格便宜，不意味着搬回家之后的工作也是免费的。

## 8. 什么情况下不要照搬

事故历史无法确认、安全性能难以检查，尤其涉及头盔、儿童安全座椅等直接保护生命的用品时，应优先考虑可追溯、保障清楚的渠道和新品。

不能可靠验证的卫生用品、药品、来源不明食品等，不属于本篇推荐的“捡漏”范围。没有验货能力和时间，也可以选择更有保障的购买方式。

## 9. 有什么边界

不交易违法、侵权或来源可疑的物品，不让省钱成为忽视隐私、卫生和用电安全的理由。平台有规则，也不等于每一单都可靠。

不要把反复刷平台、为了便宜囤货包装成低成本生活。

## 10. 在本书中怎么使用

它是购买与闲置管理的实践条目。有条件收录的是理性比较二手与新货，不是“什么都买二手”。也可以和 [租万物](05-租万物.md) 放在一起比较。

购买前的冷静期、先试后买和替代品检查，见[行为指南 · 消费购物](../行为指南/05-消费购物.md)。这些是一起用的判断方法，不需要再发明一个新理论。

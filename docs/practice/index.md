# 过学实践篇

**过学是道，具体方法是术。**

总纲讲钱、时间和精力该往哪里放；实践篇讲今天可以怎么做。方法不需要统一，判断的尺子要清楚：**有没有让日子更好过，总成本有没有更合理。**

第一次来，可以先看 [30 秒了解过学](/start/)，或者直接挑一个你现在最头疼的问题。

## 每篇都用同一把尺子

我们会说清楚：这是什么，解决什么问题，可能为什么吸引人，最有价值的部分，与哪些原则相符，普通人怎么做，以及什么时候应该停下。

不拿「有人这么说」代替证据，也不拿「省了多少钱」盖过健康、安全和长期生活品质。

## 实践之前，先过三关

1. **我真的有这个问题吗？** 别为了加入一个理论，先给自己制造一个需求。
2. **省下的是什么，付出的又是什么？** 多花一小时、少睡一觉、承担一次安全风险，都不是免费。
3. **能在我的生活里持续吗？** 适合学生的办法不一定适合照顾孩子的人，适合独居的办法也不一定适合一家人。

选一件事，小范围试一试。没有改善，就调整；没有必要，就不做。过日子不用交一份满分答卷。

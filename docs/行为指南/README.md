# 行动篇｜“过的人”行为指南

[返回全书目录](../../README.md)

> **生活成本可以低，生活品质不能低。**
>
> 不用一夜之间重做生活。先找一件最烦、最常发生、又能安全调整的小事。

这不是“省钱大全”。每个方法都要同时回答：**少付出了什么？保住或改善了什么？多出了什么代价？**

衣服少一点但好穿，通勤短一点但住得安全，订阅少一点但重要资料仍有备份。方式不同，判断是一套。

这些具体办法各管一件事，“过学”把它们背后的共同思路整理出来。这本书先讲清目标、成本与品质和基本原则，再看具体办法，最后落到每天怎么做。你也可以从眼前最需要解决的问题直接翻起。

## 先用这五步，别忙着买新东西

1. **说清问题。**例如“我每天找钥匙很烦”，比“我需要更高级的收纳系统”更具体。
2. **保住底线。**健康、安全、营养、睡眠、必要医疗与基本居住质量，不能拿来抵消小优惠。
3. **看两边的变化。**哪种成本减少，哪种增加？真正的体验有没有保住或变好？不把所有东西强换算成钱。
4. **选一个能退的小尝试。**给钥匙固定位置，比立刻买一整套收纳柜容易判断。重要支出和不可逆选择，需要更充分核实。
5. **回头看结果。**记录实际花费、时间和感受。没变好就调整，不需要为了证明自己是“过的人”硬坚持。

成本与品质怎么一起看，见[成本与品质](../成本与品质.md)；判断时可以参考[十条基本原则](../03-十条基本原则.md)。

## 网络理论和项目实践，放在同一本书里

**已有网络理论**提供了值得讨论的具体主张。大水放进饮食，长睡眠放进睡眠，薄肌放进健康与运动，二手和租万物放进消费购物。租房属于租万物的居住场景。

这些入口会链接到[网络理论篇](../04-过日子的具体方法/README.md)，保留作者、来源和当前收录范围。进入行为指南，不等于认可同名理论的全部说法。

**“过学”实践方法**是本项目依据总纲整理的日常做法，例如低维护、总拥有成本、购物冷静期和退出成本。它们可能来自大家早就在用的经验，这里的工作是整理、解释和检验，不能据此认领首创。

两种来源类型都要经过同一套成本—品质判断。名字有没有梗，不影响健康安全的底线。

# 3.5 消费购物

先问要解决什么，再看怎么买。购物的价值在买回来之后：用得上、用得舒服，也承担得起后面的负担。

<a id="shopping-secondhand"></a>

## 3.5.1 二手 / 闲鱼：买使用价值

新品不一定更适合，二手也不因便宜就值得买。先确认需要什么，再比较成色、保障和完整成本。

1. 写清用途、尺寸和必需功能，对照新品价格，计入运费、清洁和可预见维修。
2. 确认缺陷、配件和交易保障，保留沟通记录，按渠道规则验货。
3. 收到后先检验再确认，电子设备同时检查账户、隐私与数据安全。

二手可能减少购置支出，却增加搜索、验货和维修的时间。功能、卫生和可靠性都合适，省下的钱才没有换成新的麻烦。

无法核验安全历史、卫生或来源时，选择更有保障的渠道。不买来源不明、违法或直接影响生命安全且无法验证的物品，不绕过付款保障。

完整讨论：[二手消费](../02-具体生活方法/04-二手消费.md)。

---

<a id="shopping-renting"></a>

## 3.5.2 租万物：先决定怎么使用

有使用需求，不一定要取得所有权。房屋、家具、设备和工具都可以比较租、借、买，关键是所需期限和实际条件。

1. 写用途、期限和随时可用的要求，先看已有物品能否解决。
2. 将全租期费用、押金占用、交付、取还、维修与赔偿，和购买后的成本并排比较。
3. 核验物品与合同，保留交接记录；期限延长时重新计算。

租用可能减少前期支出、收纳和维护，也可能增加取还与合同负担。短期、长期和高频需求都能租，是否值得取决于总成本、稳定性和便利。

费用责任不清、供给或取还无法满足使用时，不签约。免押仍可能有信用或赔偿责任；安全、卫生和权限无法确认就停止，专业高风险设备也不能跳过资质。

完整讨论：[租万物](../02-具体生活方法/05-租万物.md)，租房是其中一项。

<a id="shopping-try-before-owning"></a>

## 3.5.3 先租 / 先试后买

想象自己会热爱摄影或露营，和真的愿意持续去做，是两回事。对价格较高、兴趣尚不稳定的用品，可以先获得一次真实体验。

1. 找实际使用机会，借用、合规试用或短租，不先买齐全套。
2. 用完看自己是否喜欢、能否安排时间，以及取还和维护能否接受。
3. 需求持续后再比较租与买的总成本；不喜欢就不必继续投入。

试用也要花钱和时间，但可能避免更大的误购与闲置负担。得到一个“不适合我”的答案，同样能减少以后的压力。

医疗、卫生、专业防护等不适合共享的品类，以及紧急必需品，不套这一步。遵守出租方和商家规则，不滥用退货；试用设备也须安全、来源可靠。

---

<a id="shopping-cooling-off"></a>

## 3.5.4 购物冷静期

倒计时和一时情绪容易让“有点想要”变成付款。对不急用的东西，等一等再看，需求往往更清楚。

1. 放进愿望清单，写用途与预算，关掉催单提醒。
2. 隔几天再看：现有物品能否解决，想买的理由是否还在。
3. 确实需要且承担得起总成本就买，不必只因折扣下单。

等待可能错过优惠，却能减少冲动购买和事后的后悔。它保留的是选择余地，不要求把真正想要的东西都忍下来。

72小时是方便记忆的参考，不是科学阈值，也不是硬规定。必要医疗、安全防护和急需工作工具不能耽误；延迟不该变成长期不敢决定。

---

<a id="shopping-substitute"></a>

## 3.5.5 先找替代方案

遇到新任务，不必立即买专用工具。家里已有的东西可能已经够用，也可能只是勉强完成、长期费劲，需要试过才知道。

1. 写清任务的必要功能，看已有物品是否满足。
2. 普通低风险任务先小试，观察是否顺手可靠。
3. 若长期不便，再按“现有东西哪里不够”选择专用品。

用已有工具能少购置、少收纳，但调整和操作也可能多花时间。真正值得保留的替代，是完成核心需要后，整体使用体验仍合适。

专业作业、卫生、防护和安全要求明确时，不能用不合格物品凑合。“完成大部分功能”不能遗漏关键功能，更不能成为危险改装的理由。

---

<a id="shopping-repair-before-replace"></a>

## 3.5.6 修优于换

一点故障就换新，可能多花钱；反复修一个不可靠的东西，也会拖累生活。修不修，要比较恢复后的可靠性和全部负担。

1. 确认故障和保修，向可靠维修渠道问清费用、预计寿命与保障。
2. 将维修费、等待时间和可靠性，与购买合用替代品并排比较。
3. 修好后检验；反复故障或安全无法保证，就换方案。

合理维修能减少重购和搬运，但检测、等待和再次故障也有代价。修好后稳定好用，才算保住了实际价值。

被召回、存在无法消除隐患或影响生命安全的物品，不勉强继续用。电路、燃气、承重等高风险维修交给合适专业人员，必要安全检查不能省。

---

<a id="shopping-mature-products"></a>

## 3.5.7 成熟产品优先

日常工具先把活干稳。新概念若只带来配件重买、操作重学和维修困难，新鲜感可能没有转化成便利。

1. 按核心功能与使用环境，核验可靠性、配件、保修和维修渠道。
2. 比较新旧方案的真实差别，新功能能解决具体问题就可以选。
3. 电子设备确认安全更新和支持期限，不选已不适合安全使用的型号。

可靠、服务完善的产品可能售价更高，却能减少试错与后续折腾。对高频工具，稳定好用通常比不断尝鲜更容易让人受益。

成熟不等于越旧越好，也不保证每件产品可靠。旧方案不满足无障碍、安全、效率或支持需要时，应考虑合理更新，具体型号仍要核验。

# 3.9 时间管理

时间也可以留给发呆、兴趣和家人。少一些重复折腾，是为了多一点能自己决定的时间，不是把每分钟都榨出收益。

<a id="time-value"></a>

## 3.9.1 把时间成本算进去

为一个小价差反复领券、跑店和刷新，钱省了一点，重要的事却没空做。省钱前也看看自己交出了多少时间与精力。

1. 估计额外操作用时和实际节省，不把满减金额都当净收益。
2. 看原本留给休息、工作或关系的时间是否被挤掉。
3. 留少数确实好用的省钱办法，太麻烦、收益太小时换个安排。

省时服务可能贵一些，却换回便利与选择余地。现金紧、时间宽裕，或喜欢研究和动手时，花时间省钱同样可能适合。

不按工资给所有闲暇统一定价，也不把休息当作没产出。赶时间不能省掉必要验货、安全检查和专业判断，钱与时间哪种更紧，要由自己的生活决定。

---

<a id="batch-tasks"></a>

## 3.9.2 批量处理

一天里多次临时采购、洗一点衣物或缴一笔账单，每件都小，反复启动与打断却很费劲。时间要求相近的小事可以适当合并。

1. 找一类重复任务先试，如采购、账单检查或简单家务。
2. 按实际用量与处理能力安排，不大量囤货、不把一天塞满。
3. 看是否更轻松；需要及时做或容易拖延的事，改回分次处理。

集中做能少准备、少出门，但也需要整段时间和储存空间。只有合并后更方便、可靠，才值得保持。

食品储存遵守可靠的保鲜与卫生要求，账单不等到批量日逾期。截止期不同、照护需求难预测或储存条件不足时，不硬凑一批，大量购买也不保证更省。

<a id="default-options"></a>

## 3.9.3 默认方案

早餐、穿搭和日用品每次从零研究，事情很小，却总占着脑子。已有满意的选择，可以先让它承担日常重复。

1. 找一个常纠结的小问题，留下两三个满意、预算能承受的选项。
2. 记下来或放到顺手位置，普通日子直接用，想换口味就另选。
3. 价格、身体或生活条件改变时重新确认。

第一次筛选仍要花时间，之后能少些比较与纠结，日常更稳定。价值在于减少重复劳动，不是剥夺新体验。

默认不等于只吃一种饭、只穿同一套衣服。特殊饮食、工作要求和新风险出现时重新判断，不为统一过量囤货，也允许产品和需求变化后换方案。

---

<a id="practical-automation"></a>

## 3.9.4 合理自动化

工具可以少一些重复输入和惦记，也可能让人反过来伺候工具。先从稳定、规则清楚的一件事开始。

1. 用现有工具做简单提醒、固定清单，或设置合适的自动支付。
2. 自动支付前确认金额、周期、余额、取消方式与提醒，只给必要权限。
3. 保留账单检查、异常提醒和手动办法，比原任务更费心就停用。

设置、软件与后续维护可能有费用。长期确实更省事、少遗漏，而财务和数据仍可控，才有实际收益。

金额变化大、易误付款或需要个人判断的事项，不直接全自动。自动续费仍受预算约束，支付不能永远不检查；不随意上传敏感资料或共享密码，重要流程留备选。

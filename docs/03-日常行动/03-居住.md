# 3.3 居住

家是每天过日子的地方。看房子时，把自己的普通工作日带进去，别只带相机。

<a id="housing-rental-total"></a>

## 3.3.1 租万物 · 租房：看完整住房成本

月租省下来，日子可能赔在路上。选房不仅看账单，还要看通勤、睡眠、居住安全和能否稳定住下去。

1. 列不能退让的条件，比较月租、交通、水电、服务费、押金占用和搬家费用。
2. 按上班时段试走通勤，实地检查噪声、通风、潮湿、用电、门锁与疏散条件。
3. 核验出租权限，读清维修、涨租、押金和解约规则，保留合同、交接与付款记录。

实地核验需要时间，合适的房源也可能租金更高。多付的钱是否换来安全、舒适和可支配时间，要放在自己的预算与日常安排里判断。

无障碍、夜间通勤、居家工作和照护有不同要求，不能统一房型与距离。危险房源或基本居住质量不达标直接排除，不用低租金抵消。

完整讨论：[租万物 · 租房](../02-具体生活方法/租万物/01-租房.md)。

<a id="housing-high-use-spaces"></a>

## 3.3.2 高频空间优先

床、厨房、卫生间和工作位置天天用，预算却先流向低频展示区。先解决反复出现的不便，一次小改善可以每天受用。

1. 回想一周常用的地方，找一个具体麻烦，比如桌面太暗或厨房操作不顺。
2. 先试换位置、清出操作面，必要时再花钱改善；与同住的人确认需要。
3. 观察一周是否更顺手，再处理下一处。

布局和灯光调整可能需要初期支出，但能少绕路、少收拾，让休息和家务更舒服。已经好用的地方，不必为了统一风格再改一遍。

合租和租赁先确认权限，照护家庭也要兼顾共同需要。不自行改动有风险的电路、燃气或结构，不挡通道；睡眠环境已有安排时，避免重复购买。

<a id="housing-useful-space"></a>

## 3.3.3 空间利用率

面积是数字，好不好住是每天的事。用不到的面积持续占房租，小空间堆满家具也会让生活处处受阻。

1. 按睡觉、吃饭、做饭、工作、洗漱和储物，找出实际路线上的堵点与闲置区。
2. 先挪已有家具、清理无用占位，再决定是否添收纳或换房。
3. 比较房源时看可用布局、采光、通风和共同生活需要，不只看面积单价。

调整布局需要时间，也可能有必要支出。换回的是够用的活动空间和日常便利，不是把家压到越小越好。

儿童、无障碍、照护和居家工作应保留足够活动与私密空间。不接受违法隔断、消防隐患或基本活动受限；折叠家具也要牢固、安全、好操作。

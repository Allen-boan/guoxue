# 3.15 旅行与娱乐

休息、好奇、陪伴和兴趣，都是真实的收益。行程数量与花费数字，只能帮助安排，不能替你决定什么值得。

<a id="guide-travel-not-checklist"></a>

## 3.15.1 旅行不是打卡竞赛

景点排得满，赶路和排队也排得满，回来比出发前更累。旅行的收获不需要用去过多少地方证明。

**怎么做：**和同行者各选最想体验的事，核对体力、兴趣与预算。按交通和休息需要留余地，删掉很远又不太想去的项目；现场按状态调整，不因门票已买就硬撑。

**取舍：**看过的地方可能少了，喜欢的体验可能花得更多，却能换来真实感受与相处时间。本人享受密集探索，也可以保留适合自己的节奏。

**边界：**留白仍需确认交通、营业、预约和住宿，遵守团队约定与安全时间窗口。不把慢游偏好强加给同行者，也不以疲惫换行程成绩。

<a id="guide-off-peak-leisure"></a>

## 3.15.2 淡季错峰

时间有弹性时，可以比较不同日期的价格与拥挤程度。但淡季便宜的票，未必意味着整趟旅程更省、更好玩。

**怎么做：**比较交通、住宿与活动的实际总价；核实营业、天气、交通和安全限制，确认想要的体验仍在。和同行者算清请假、照护及退改代价，再预订。

**取舍：**合适的错峰可能减少等待与开销，核实条件却需要投入。若请假成本高、同行困难或核心体验消失，旺季也可能更适合。

**边界：**不承诺淡季一定便宜、人少或更好。停业、交通减少、恶劣天气与不可退费用都要确认；安全和必要服务不能用折扣补偿。

---

<a id="guide-entertainment-hour-cost"></a>

## 3.15.3 每小时娱乐成本

游戏、会员和设备买了不少，实际却没怎么用。按使用时间粗算，可以看见被遗忘的娱乐支出。

**怎么做：**把同一时期的实际支出除以实际娱乐小时数，没使用就记为未使用。再写下好不好玩、是否珍惜、有没有影响睡眠与必要事务；优先调整不用或不享受的开销。

**取舍：**这个比值帮助比较相近选择，不负责给演出、纪念、旅行或陪伴定价。短暂却珍贵的体验，也可能非常值得。

**边界：**不为摊薄价格强迫多玩，更不能让比值掩盖沉迷与健康问题。费用和时长采用同一范围，估算承认误差；快乐不是按小时排列的榜单。

# 3.17 数字生活

软件和云服务帮人做事，也需要管理。减少重复工具与续费时，资料、安全和必要访问能力要一起保住。

<a id="guide-fewer-apps"></a>

## 3.17.1 减少重复 App

同一任务装好几个软件，通知、账号和权限会一起增加。留下真正顺手的工具，比追求软件数量更少有用。

**怎么做：**选一个任务类别，比较实际功能和权限。确认替代工具能满足需要，先迁移并核验资料，再停用重复软件；另查订阅、账号和登录方式是否需要处理。

**取舍：**迁移和适应要花时间，之后可能减少维护与打扰。集中到少数工具，也要考虑服务中断和退出能力；必要的工作、照护及无障碍功能应保留。

**边界：**卸载 App 不等于取消续费或删除账号。不为少装一个软件使用来源不明、权限过大的替代品，重要资料和访问方式先确认再删。

<a id="guide-subscription-audit"></a>

## 3.17.2 定期盘点数字订阅

会员早已不用，自动续费却继续扣款；云服务想取消，又怕文件打不开。订阅需要按实际用途管理。

**怎么做：**从账单和各服务订阅页列出价格、续费日期与用途。不用的准备取消；涉及云盘、邮箱或文档，先查降级规则，迁移资料并验证完整、可打开，再取消并保存结果，检查后续账单。

**取舍：**盘点和迁移需要时间，可能要付过渡费用。保留必要服务保护资料与工作，同样可以改善生活；省钱不必等于全部退订。

**边界：**以服务实际的取消、容量和保留规则为准，不假定资料永久保留。卸载 App 或删除支付方式未必取消成功；资料尚未迁移核验时，不贸然停止重要服务。

<a id="guide-data-backup"></a>

## 3.17.3 数据备份

照片、作品和文件只有一份，设备坏了、误删或账号出问题，就可能再也找不回来。备份要能恢复，才算有用。

**怎么做：**

1. 把无法轻易重建的资料存到可靠位置，再留一份于独立设备或可信服务；同一硬盘的另一文件夹不算独立备份。
2. 确认能登录或解锁，妥善保存恢复方式，敏感资料按需要加密。
3. 定期把部分文件恢复到另一位置，检查内容完整、可以打开，按更新频率补备份。

**取舍：**存储和检查需要钱与时间，却保护记忆、作品和工作。平时没恢复过，不代表这笔投入无用。

**边界：**同步误删可能同步到副本，同步不自动等于备份；确认独立副本或可恢复历史。删除原件、清空设备或取消服务前，先验证完整性与恢复能力。备份不能保证零损失，也不能把敏感资料交给陌生服务。

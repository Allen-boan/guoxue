# 3.16 安全与风险

必要防护、应急和备份，是为了在意外发生时仍有退路。平时用不上，不代表没有价值。

<a id="guide-safety-reserve"></a>

## 3.16.1 安全冗余

只保留刚好够用的安排，一个停供、故障或资料丢失，就可能影响基本生活。

**怎么做：**按家庭情况列出后果严重、现实可防的风险，先补最关键的退路：必要应急物资、可恢复的资料备份或合适保障。定期检查有效期、可用性与家人是否会使用；保险要读清保障、除外责任和费用。

**取舍：**备用安排占预算、空间，也需要维护，却能降低中断后的损失。数量和保障程度按实际风险决定，不靠不断购物缓解焦虑。

**边界：**不盲目购买重复装备，也不假定保险覆盖一切。安全冗余不能保证零风险，不能替代安全习惯；重要保障选择需充分理解条件，并保留基本生活预算。

---

<a id="guide-essential-protection"></a>

## 3.16.2 不省必要防护的钱

头盔、防护用品和电器只看售价，忽略适配、合规或损伤，省下的购入费用可能换来不可逆后果。

**怎么做：**按活动与当地适用要求确认防护需求，从可核查渠道选择合格、用途和尺寸合适的产品。读说明，正确佩戴或安装，检查磨损、损坏和更换条件；不确定是否可靠，就停止依赖并核实。

**取舍：**必要防护和更换值得投入，但贵不自动合格，便宜也不自动危险。现有产品仍合格适用，无须为身份标签升级。

**边界：**普通用品不能冒充专业防护，有损伤史不能只凭外观判断安全。防护不是冒险许可，仍须注意环境风险和正确使用。

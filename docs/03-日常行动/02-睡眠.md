# 3.2 睡眠

睡觉不该总排在“剩下的时间”里。先让休息有位置，再研究装备。

<a id="sleep-adequate"></a>

## 3.2.1 长睡眠理论：保障合理睡眠

睡眠被刷屏和无意义的忙碌挤掉，白天再靠刺激和补救产品硬撑，未必省了什么。先给休息真实的时间，观察自己是否恢复得更好。

1. 记录几天睡觉、起床和白天状态，找最常挤占睡眠的可改变因素。
2. 先改一个环节，例如提前结束无目的刷屏，按实际需要安排尽量规律的休息。
3. 看白天的感受与生活功能，不只追手环分数或卧床时长。

这可能需要减少晚间娱乐，或协调工作与照护分工。得到的是合适的休息机会，不是人人相同的时长和效果。

不是越睡越好，也不自行用酒精或药物追时长。持续失眠、明显嗜睡或睡很久仍异常疲惫，应寻求专业评估；轮班和照护家庭先争取可行支持。

## 3.2.2 睡眠环境优先

卧室看起来漂亮，却一直忍着噪声、刺眼光线或不合适的床具，展示花费没有转化成睡得舒服。先处理真正打扰休息的地方。

1. 找最明显的干扰：光、噪声、温度或床具不适，一次先处理一项。
2. 先试可行的小调整，再比较产品；床具注意尺寸、实际体验和退换条件。
3. 用一段时间观察是否更舒服，没有效果就停下，不继续叠加设备。

遮光和合适床具可能增加前期支出，若每天都用得上，真实改善值得考虑。价格高本身不能证明睡眠条件更好。

环境改善不能代替疾病、工作安排或居住隐患的处理，也不保证解决所有睡眠问题。不堵通风和逃生路径，注意电器与取暖安全；儿童等特殊人群按可靠专业要求安排。

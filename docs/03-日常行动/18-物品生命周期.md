# 3.18 物品生命周期

付款只是开始。以后如何使用、维护、搬走或停止服务，都会影响这件东西的真实成本。

<a id="guide-exit-cost"></a>

## 3.18.1 考虑退出成本

物品买时便宜，后来搬不动、卖不掉、没配件，或者服务退不了，结束使用也会变成负担。

**怎么做：**购买前考虑“获得 → 使用 → 维护 → 退出”：用多久、谁能维修、怎么搬走或停服务。查清转卖、转赠、回收和处理的真实条件与费用；退出时清理个人资料及账号绑定，说明已知故障与风险。

**取舍：**方便维修和退出的方案可能贵些，却更适合搬家或需求变化。转售价只是估算，不能为期待高价卖出而买不需要的东西；按购入减转售收入算总账时，不再重复加同一转售损失。

**边界：**不能把危险物品或处置责任偷偷转给别人。电池、电器、药品按当地适用规定处理，不自行拆危险部件；资料清理不确定时先核实，再移交设备。

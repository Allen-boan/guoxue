# 3.7 交通通勤

路上的时间也是日子的一部分。交通选择要看钱、时间、疲劳和安全，也要给不同天气与身体条件留余地。

<a id="commute-time-cost"></a>

## 3.7.1 通勤时间也是成本

租金省了一些，休息、做饭和陪伴的时间却被路程挤掉，未必更划算。选住处时，把普通上下班的一天算进去。

1. 按平常时段试走路线，记录门到门时间、换乘和常见延误。
2. 将租金、交通费、往返时间与居住体验并排比较。
3. 按预算和责任选能长期承受的方案；暂时搬不了，也可先减少一项路上折腾。

住得近可能更贵，搬家也有一次性费用。多付的钱有没有换回休息与自由时间，要按自己的资源余地判断，不统一给时间标价。

预算、照护和房源限制不同，离公司近不一定最好，也不选明显不安全的房屋或路线。

完整看房与合同检查：[租万物 · 租房](../02-具体生活方法/租万物/01-租房.md)。

<a id="effective-transport"></a>

## 3.7.2 最短有效交通

地图上的最快路线，未必门到门最快；低车费也可能换来多次换乘和疲劳。交通工具服务行程，不必负责证明身份。

1. 比较两三种走法的完整时间、费用、换乘、天气和体力要求。
2. 按工作日、买菜、雨天等实际场景试用，不用一种方式包办所有事。
3. 留常用路线和可靠备选，条件变了再调整。

打车、停车或合适装备可能值得付费；自有车辆还有保养、停放和退出成本。选择让这趟出行安全、顺手、负担可承受的安排。

行动不便、带孩子、夜间或恶劣天气出行，要重新判断路线。遵守交通规则，必要头盔和防护不省，也不为赶时间冒险；“最短有效”不是比公里数或速度纪录。

<a id="local-life-circle"></a>

## 3.7.3 15 分钟生活圈

买菜、取件和运动各跑一头，小事也能占掉大量时间。把常用服务安排得近一点、顺一点，日常会轻松不少。

1. 标出每周真会用的地方：买菜、基础餐食、运动、取件与必要服务。
2. 尽量顺路完成；选住处时，核查配套的价格、质量和实际可达性。
3. 保留合适医疗、工作与重要关系的可达性，不为凑小圈子舍弃它们。

了解周边要花些时间，便利地段也可能有溢价。是否值得，要看自己真实使用频率和减少了多少跑腿负担。

15分钟只是方便理解的目标，不是硬标准。偏远地区、轮班和特殊照护未必能短距离解决；附近有店也不代表可靠，不能只看地图上的距离。

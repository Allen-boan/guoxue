# 3.6 物品使用与维护

买价只是账单的第一行。东西买回家之后，要花多少力气照料、能带来多少便利，才逐渐看得清。

<a id="ownership-total-cost"></a>

## 3.6.1 总拥有成本

低买价后面可能跟着耗材、能源、维修和收纳。比较家电、家具或设备时，把取得、使用和退出连起来看。

1. 按预计期限算金钱账：购置价＋耗材、维修、能源等支出－保守预计的转售收入。
2. 另看时间、空间、精力和安全风险，同一项支出只算一次。
3. 比较满足需求的方案，检查预算与现金流，再用实际使用修正预估。

查关键信息需要时间，可靠的选择也可能前期更贵。多付的钱若能换来长期稳定、省心的使用，才有实际意义。

购置价减去转售收入已包含转售损失，不再重复加算。时间不设统一折价，健康安全也不能用便宜抵消。小额简单用品不用复杂表格，紧急必需事项不能为算账耽误。

---

<a id="ownership-low-maintenance"></a>

## 3.6.2 低维护优先

效果差不多的东西，清洗、耗材和维修负担可能很不同。买前问一句：以后好不好伺候？

1. 看清清洁频率、所需耗材、配件供应和维修办法。
2. 核心体验接近时，优先比较好洗、耗材少、维修明确的方案。
3. 留下必要保养安排，用过再看是否真的省事。

低维护的产品可能买价更高，或少一些花样功能。若能持续减少清洗和操心，而使用体验仍合适，这笔投入就有价值。

低维护不是不维护，必要清洁、防护和安全检查不能省。医疗、无障碍、工作或重要兴趣确实需要复杂功能时，不为简单而舍弃；耐用也须看具体产品，不能靠标签保证。

---

<a id="ownership-high-frequency"></a>

## 3.6.3 高频用品优先投入

每天被鞋不合脚、椅子不舒服困扰，却不断买低频展示品，预算没有解决真正的麻烦。可以先检查每天都在用的东西。

1. 找一个高频用品，写清持续出现的具体问题。
2. 先试调整与维护，再比较能解决问题的升级；眼镜等专业需要找可靠服务。
3. 预算内购买后，观察是否改善，没有真实变化就不继续加价追配置。

床、鞋或通勤工具可能需要较大的一次性投入。判断理由是每天更舒服、顺手或可靠，不是使用频率高就该买最贵的。

现有物品已够用时不必升级。低频安全用品仍可能必须投入，不能因用得少淘汰；购买不能透支必要生活费用和财务缓冲。

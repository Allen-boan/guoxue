# 3.4 穿衣

衣服要适合自己的身体和生活。好穿、合用、自己喜欢，比替别人交一份体面答卷重要。

<a id="clothing-fewer-useful"></a>

## 3.4.1 少而好穿

衣柜很满却总觉得没衣服穿，常常因为买来的衣服不合身、不好搭或护理太费劲。少买闲置，多照顾常穿的那几件。

1. 看最近常穿的衣服，记下舒服、合身、好清洗的特点，找真实缺口。
2. 按气候、工作和洗衣频率补够用的数量，试穿动作与搭配，不按统一件数清衣柜。
3. 暂缓重复购买，不合适的按状态修补、转让或处理。

合适耐穿的衣服可能单价更高，却能减少闲置、储存和每日搭配的负担。审美带来的真实快乐也有价值，不必把衣柜变成只剩功能的清单。

制服、专业防护、特殊体型和身体需求先满足。不能为少买而缺少保暖、防晒或工作防护，数量够不够由实际生活决定。

<a id="clothing-cost-per-wear"></a>

## 3.4.2 单位穿着成本

一件打折衣服只穿一次，未必比常穿的合身衣服划算。价格除以穿着次数能辅助比较，但次数要按真实习惯估计。

1. 买前估计多久会穿一次，别按“以后天天穿”计算。
2. 用价格除以保守的预计次数，另外考虑清洗、修补、舒适和场合需要。
3. 穿过一段时间回看实际次数，修正下一次选择。

常穿能分摊买价，却不能把不舒服变成值得。更高的前期价格只有带来合用的实际体验，才有理由承担。

不为摊薄成本硬穿不合适的衣服，也不为“长期划算”负债。专业防护、礼仪场合和少见但必要的衣物，不能单靠次数判定价值；预计次数也不是保证。

---

<a id="clothing-standard-basics"></a>

## 3.4.3 基础用品标准化

袜子已经合适，补货时不必重新比较几十个款式。对稳定的基础需要，保留好用的选择，能少一点日常纠结。

1. 从一种常用基础用品开始，试穿后记下品牌、型号、尺寸和感受。
2. 更换时先看原款是否仍合适，确认材质与规格有没有变化。
3. 按使用和洗衣频率补货，身体、气候或需求变了就重新选择。

第一次寻找合适款仍要花时间，后面的复购可以减少重复比较。价值在于舒适、方便和省心，不在于所有用品都长得一样。

默认不是永久，复购也不是囤货。原款不适合时别为统一忍着；优惠再大，也不必买超过实际需要的库存。

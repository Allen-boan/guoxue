# 3.1 饮食

先让饭把人照顾好，再让照片好看。营养、卫生和口味都有位置，一顿真正喜欢的饭也不必被当作浪费。

<a id="food-basics"></a>

## 3.1.1 基础饮食优先

买了不少写着“健康”的食品，正餐却常常凑合，钱未必花到了身体真正需要的地方。先把每天的饭吃好，再考虑补充什么。

1. 看常吃的几顿饭，是否有主食、蛋白质食物、蔬菜水果；先补最明显的缺口。
2. 留几种买得到、做得来、吃得惯的搭配，外食也按食物本身选择。
3. 基本饮食稳定后，再判断昂贵食品有没有额外价值；保健品不替代正常吃饭。

准备食物可能多花时间，也要留出必要预算。省下的是无用的标签溢价，保住的是营养、安全和稳定的一日三餐。

不靠少吃、单一饮食或来源不明的食物省钱。食物过敏、孕期及疾病相关饮食需要，应按自己的情况和可靠专业建议安排。

---

<a id="food-daily-and-experience"></a>

## 3.1.2 日常饭与体验饭分开

每顿都追求精致，预算和精力可能吃不消；天天将就，又会失去吃饭的快乐。日常饭负责可靠，期待的一顿负责好好享受。

1. 给工作日留几个方便、合口味、总价可接受的选项。
2. 真想吃的一顿按预算和日程安排，与重要的人相聚也算真实价值。
3. 吃完看实际感受：值得就再去，只剩拍照的疲惫就换方式。

简单的日常安排能减少选餐和做饭的负担，体验饭则需要另外留出钱和时间。两者的意义不同，不必用同一标准比较。

不为攒一顿大餐长期吃不够，也不把体验饭变成攀比或报复性进食。饮食限制、轮班和照护安排复杂时，先保证合适的食物能吃得上。

---

<a id="food-less-packaging"></a>

## 3.1.3 少为包装买单

同样能满足需要的食品，差价可能来自食材和保鲜，也可能只是联名与网红标签。值得付钱的，是自己真正用到的部分。

1. 按可食用量比较同类食品的价格，先确定自己能吃多少。
2. 分清差价来自食材、保存、便携还是标签；有实际作用的包装可以付费。
3. 买正常用量，吃过再判断。大包装吃不完，单价再低也可能浪费。

比较需要一点时间，差价很小时不必无限研究。目标是在卫生、口味和便利都合适的前提下，少付无用的溢价。

需要特殊配方、便携分装或无法确认散装卫生时，完整包装可能更合适。过期、破损、信息不清和储存不当的食品不能因便宜接受；喜欢设计也可以量力购买。

<a id="food-water"></a>

## 3.1.4 大水理论：把日常饮水安排顺手

常忘带水、临时买饮料，可以先改善取得水的方式，不必先买一套设备。水源安全、容器好洗、携带方便，比喝水挑战重要。

1. 找一个经常饮水不方便的场景，用已有、材质适合且好清洗的容器。
2. 确认安全水源和补水点，按身体、环境与活动情况安排，及时清洗。
3. 用几天看看是否顺手；太重、漏水或难洗，就换小杯或可靠补水点。

自带水可能少花饮料钱，但携带和清洗也有负担。衡量的是日常是否更方便，不是喝了多少、买了多大的瓶子。

不强迫大量饮水，不喝来源不明的水，不用喝水替代饮食和治疗。有饮水限制等医嘱须遵从，高温高强度活动也不能照抄日常安排。

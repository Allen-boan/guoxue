# 附录｜过日子词典

这些词是为了把生活问题说清楚。读起来比过日子还费劲，就该改写了。

## “过学”

研究普通人怎样降低生活和维护成本、减少无效消耗，同时获得、维持甚至提升真正生活品质的一套思想与方法。

最高纲领：**生活成本可以低，生活品质不能低。**

## “过的人”

愿意把资源花在真正影响生活品质的地方，也愿意砍掉无效消耗的人。

这是自愿认同，不按收入、价格、品牌或生活方式划等级。

## 道与术

**道**是判断方向和原则：什么值得、守住什么、怎么比较。

**术**是具体方法：怎么喝水、休息、运动、租房、购买或租用。

原则帮助我们判断方法，方法再放回每个人的实际生活里检验。它们不是两份彼此无关的清单。

## 生活品质

生活的实际体验与可靠程度，包括健康、安全、合理饮食、睡眠、居住、资源余地和重要关系。

个人的舒适、兴趣和美感，也可以是生活品质的一部分。它不能只靠价格、排场或别人眼里的精致来衡量。

## 生活去溢价

去掉没有给你带来实际价值的额外成本。比如只为展示身份支付的费用，或者明明用不上却被催着升级的功能。

可靠品质、省心服务、真心喜欢的设计，可能值得多付钱。贵出来的部分有没有用，才是要问的事。

## 维护成本

为了让一个物品、安排或状态持续存在，要不断付出的金钱、时间、精力和注意力。

买来以后的清理、维修、续费和操心，都算在内。必要维护能避免更大的问题；低维护要减少的是无效折腾。

## 四种资源

**钱、时间、精力、注意力。**

便宜但耗时、便宜但累人、便宜但一直占着脑子，都需要一起算账。

## 核心需求

你真正想解决的问题。比如“需要睡得安静”，比“需要更贵的房子”更接近一个能判断的需求。

除了健康、安全等底线，核心需求还要看每个人的实际情况，没有一张所有人共用的购物清单。

## 表面需求

还没拆清楚的购买或生活要求。它可能来自习惯、营销、比较，也可能只是尚未说清的真实喜好。

先问原因，再决定是否投入，不必见到一个欲望就急着否定。

## 真实使用价值

一个东西实际带来的功能、体验、便利，或者你珍视的情感价值。

使用频率、效果和可靠性可以帮忙判断。但低频、必要的安全用品也有价值；天天用却天天难受，也不会自动变得划算。

## 长期成本

从取得、使用、维护到退出的全部成本，包括可以预见的风险和放弃其他选择的代价。

未来不确定，就把假设和未知写清，不装作已经知道答案。

## 收录状态

| 状态 | 含义 |
| --- | --- |
| 正式收录 | 主张、价值和边界比较清楚，进入实践篇，仍要看个人情况。 |
| 有条件收录 | 在特定条件下有用，条件要写在显眼处。 |
| 观察中 | 具体主张、收益或风险还有待了解，暂不作为已认可的方法推荐。 |
| 不予收录 | 当前主张和原则或底线有明确冲突，需要说明原因。 |

收录描述的是“过学”对具体方法的判断，不是给作者或使用者打分。有新材料，判断可以更新。

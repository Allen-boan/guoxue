# 附录｜过日子词典

这些词是为了把生活问题说清楚。读起来比过日子还费劲，就该改写了。

## “过学”

研究普通人怎样降低综合生活成本、减少无效消耗，同时获得、维持甚至提升真正生活品质的一套思想与方法。

最高纲领：**生活成本可以低，生活品质不能低。**

## “过”

“过学”里的“过”，取自“过日子”。

它不是单纯省钱，而是减少没必要的花费、折腾和消耗，把钱、时间和精力留给真正影响生活品质的事，让日子更舒服、更健康、更省心，也能长久维持。

## “过的人”

愿意把资源花在真正影响生活品质的地方，也愿意砍掉无效消耗的人。

这是自愿认同，不按收入、价格、品牌或生活方式划等级。

## “过不过”

一句顺口的问法：**这个办法到底“过不过”？**

问的是，一个理论、办法或生活选择，是否符合过学的基本想法：减少无效成本，保住或改善真正的生活品质。

不是比谁更能省，也不是给人的生活打等级。适合自己、说清代价、守住底线，才有讨论的意义。

## 具体办法与共同思路

喝水、睡觉、租房、买东西，各有具体办法。共同思路，是把这些办法背后相通的想法整理出来，帮助我们面对新的生活问题。

一个方法可以对应多条原则，行动结果也可以帮助我们修正原来的判断。

## 综合生活成本

不只有金钱，还有时间、精力、注意力、空间、维护、决策、情绪、机会，以及长期的健康与安全代价。

不同方面一起看，但不强行加成一个金额。一件事的维护同时涉及钱和时间，要说明两种影响，不能把同一笔代价重复计算。

完整定义见[成本与品质](../成本与品质.md)。

## 生活品质

生活品质，不是你拥有的东西有多贵，而是你每天真实的生活体验有多好。

包括健康、睡眠、营养、舒适、安全、便利、时间自主、情绪状态、重要关系、真实体验、稳定性和长期可持续性。

个人的舒适、兴趣和美感，也可以是生活品质的一部分。它不能只靠价格、排场或别人眼里的精致来衡量。

## 生活去溢价

去掉没有给你带来实际价值的额外成本。比如只为展示身份支付的费用，或者明明用不上却被催着升级的功能。

可靠品质、省心服务、真心喜欢的设计，可能值得多付钱。贵出来的部分有没有用，才是要问的事。

## 维护成本

为了让一个物品、安排或状态持续存在，要不断付出的金钱、时间、精力和注意力。

买来以后的清理、维修、续费和操心，都算在内。必要维护能避免更大的问题；低维护要减少的是无效折腾。

## 四种资源

**钱、时间、精力、注意力。**

便宜但耗时、便宜但累人、便宜但一直占着脑子，都需要一起算账。

这是理解资源的起点，不是完整的成本清单。空间、维护、决策和长期风险等，还要放进综合生活成本里。

## 核心需求

你真正想解决的问题。比如“需要睡得安静”，比“需要更贵的房子”更接近一个能判断的需求。

除了健康、安全等底线，核心需求还要看每个人的实际情况，没有一张所有人共用的购物清单。

## 表面需求

还没拆清楚的购买或生活要求。它可能来自习惯、营销、比较，也可能只是尚未说清的真实喜好。

先问原因，再决定是否投入，不必见到一个欲望就急着否定。

## 真实使用价值

一个东西实际带来的功能、体验、便利，或者你珍视的情感价值。

使用频率、效果和可靠性可以帮忙判断。但低频、必要的安全用品也有价值；天天用却天天难受，也不会自动变得划算。

## 长期成本

从取得、使用、维护到退出的全部成本，包括可以预见的风险和放弃其他选择的代价。

未来不确定，就把假设和未知写清，不装作已经知道答案。

## 单位使用成本

支出除以实际使用次数或时长，是观察是否真在使用的辅助视角，不是生活价值的总分。

预计会用一百次，和已经用了五次，是两回事。必要安全用品和难得的体验，也不能因为使用频率低就被判为浪费。

## 总拥有成本

看取得、使用、维护和退出的完整代价。金钱账可以按购置及使用支出减去实际转售收入记录，再单独描述时间、精力、空间和风险。

不能同时把完整购置价和购置到转售的差价都当成额外损失累加。具体做法见[物品使用与维护](../行为指南/06-物品使用与维护.md)。

## 退出成本

以后不用了，还需要付出的搬运、转卖、清理、回收或处理代价。购买只是开始，不是生命周期的终点。

具体做法见[物品生命周期](../行为指南/18-物品生命周期.md)。

## 来源类型

**已有网络理论：**保留具体主张、作者与来源，没有找到的写“待补充”。

**“过学”实践方法：**本项目依据总纲整理的方法。整理不等于首创，也不意味着适合所有人。

两种来源都要回答同样的成本、品质、适用条件和风险问题。

## 收录状态

| 状态 | 含义 |
| --- | --- |
| 正式收录 | 主张、价值和边界比较清楚，进入实践篇，仍要看个人情况。 |
| 有条件收录 | 在特定条件下有用，条件要写在显眼处。 |
| 观察中 | 具体主张、收益或风险还有待了解，暂不作为已认可的方法推荐。 |
| 不予收录 | 当前主张和原则或底线有明确冲突，需要说明原因。 |

收录描述的是过学对具体方法的判断，不是给作者或使用者打分。有新材料，判断可以更新。

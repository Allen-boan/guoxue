# 关于过的人

**过学**，副标题是**过的人｜全民大过日子时代**。

这里是“过学”的公开官网、精神总部、理论阵地，也是从短视频、社交媒体、搜索和朋友转发来到这里的人，继续了解“过的人”的入口。

精神总部有梗，生活问题认真。没有考试，也不发“比别人更会过”的证书。

## 我们想做的事

把互联网里分散但有价值的生活方法整理起来，讲清它们解决的问题、共同原则和适用边界。让普通人能找到今天就用得上的内容，也能看懂为什么某种方法值得尝试。

这项工作会持续扩充，第一版不声称已经收录全网，也不会用内容数量冒充理论完整度。

## 我们怎么做

- **先给人看：**短句、具体例子、简单导航，读完知道怎么判断。
- **再把理论讲稳：**保留收益，也把限制、风险与不同人的条件写出来。
- **最后照顾维护：**底层保留稳定编号与结构，让公开协作和未来 Agent 有据可查。

也就是 **Human First，Agent Ready**。

## “总部决议”是谁作出的

目前由项目维护者进行人工整理与审核。“总部决议”是本站对明确主张的收录判断，不是权威认证，也不是医疗、财务等专业服务。

收录不等于赞同某个名称下的全部说法。正文应说明被讨论的主张、适用条件和来源状态；有问题可以补充材料、提出异议、申请修订。

目前由人维护。未来工具可以辅助核对原则、整理证据、提示风险，正式收录仍需要人工复核。

## 能不能贡献

可以。发现一个新生活方法，找到更准确的出处，试过某个方法后发现重要边界，或者觉得某段话不够清楚，都值得提出。

不需要会写代码。网站的 GitHub 入口中可以找到 Issue 与[参与说明](https://github.com/Allen-boan/guoxue/blob/main/CONTRIBUTING.md)。

提交时把“它是什么、解决什么、为什么值得、哪里有风险、来源在哪里”说清楚。亲身体验可以标为个人经验；没有证据的地方就留白。

## 我们给自己留的规矩

不编造作者、出处、数据或研究。不同立场可以讨论，针对生活条件的嘲讽和羞辱不能替代论证。

**不是少花钱，是少给不重要的东西花钱。**

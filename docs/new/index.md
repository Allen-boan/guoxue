# 过学新论

**互联网天天有新说法，总部先把账算明白。**

这里研究新的生活主张：它解决什么问题，有没有实际价值，与过学哪些原则相符，又在什么地方需要画线。

「像过学」不等于事实已经可靠，「收录」也不等于适合所有人。先理解具体主张，不急着按名称站队。

## 一个新说法进来，先回答这些

1. **它到底在说什么？** 把原话和本人的解释分开，同名不同义要分别讨论。
2. **它替谁解决什么问题？** 没有真实问题，就别急着找适用人群。
3. **省下了什么，又增加了什么？** 钱、时间、精力、注意力都进账。
4. **生活品质有没有改善或至少保住？** 健康、安全、营养、休息和必要医疗不能被价格盖过去。
5. **普通人能不能做，什么时候不该做？** 给出条件，不许诺人人有效。
6. **有没有可靠来源和可核验依据？** 转述不能自动升级为证据。
7. **是不是旧方法的新名字？** 可以收别名，不必硬造一门新学说。

## 总部怎么标状态

| 状态 | 意味着什么 |
| --- | --- |
| 正式收录 | 具体主张、依据与边界经过确认，进入实践体系；仍不是人人适用 |
| 有条件收录 | 仅在写明条件、范围或修改后符合原则 |
| 观察中 | 具体主张、收益或风险尚不清楚，或关键证据不足，暂不建议按它实践 |
| 不予收录 | 具体主张与核心原则冲突，或存在无法接受的问题；应说明理由 |

状态描述的是**本项目对具体主张的判断**，不是给提出者或使用者评高低。发现新依据，可以修订；发现问题，也可以撤回。

找到原作者，只能确认主张来自哪里。它有没有实际收益、是否适合你、健康与长期成本怎样，仍需另外判断。有条件收录针对每篇列明的主张和边界，不代表作者所有观点都进入过学体系。

## 提交一条新论

在 [GitHub 提交理论线索](https://github.com/Allen-boan/guoxue/issues/new/choose)，写清：

- 理论名称和一句话介绍；
- 解决什么问题，你为什么认为它符合过学；
- 可能的问题、适用条件和原始来源；
- 你自己的实践观察，明确与外部证据区分。

没有找到源头也可以提出，但请直接写「准确出处待补充」。涉及健康和安全的主张，尤其不能用个人感受代替可靠依据。

目前由人整理和审核，尚未实现 Agent，也没有自动追踪全网。未来辅助工具可以帮忙拆解和对照规则，正式收录仍需清楚的依据与可追溯的复核。

从 [过学基本原则](/principles/) 看判断尺子，去 [实践篇](/practice/) 看完整例子。

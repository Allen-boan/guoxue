# 第五章｜新方法怎么判断

网上又来了一个新理论。先别忙着站队，也别因为名字听起来玄，就把有用的部分一起扔掉。

“过学”关心的是：**这个办法，能不能让真实的日子更好过？**

## 1. 先听懂它在说什么

把一句流行话拆成三个部分：

- **主张：**它具体建议你做什么？
- **对象：**它想帮谁解决什么问题？
- **条件：**在什么情况下有用，又在什么情况下不适合？

“所有东西都该租”和“根据自己的使用需要，比较租与买”，听着相近，实际是两回事。租房可以是长期、高频的使用，租工具可能只是临时需要；都得把条件说清楚。不要拿一个最夸张的版本，替所有使用这个名字的人下结论。

有作者和原始链接，就列出来；没找到就写“待补充”。自己的理解和经验，也请说清楚。

## 2. 再看综合成本，不只看省了多少钱

| 成本 | 问自己一句 |
| --- | --- |
| 钱 | 少付了什么？还有哪些后续费用？ |
| 时间 | 省下了时间，还是为了省一点钱忙了半天？ |
| 精力 | 做起来更轻松，还是多了一套需要天天维护的任务？ |
| 注意力 | 用完就能放下，还是一直惦记着规则、账单和进度？ |
| 空间与维护 | 它占了多少地方，后续还要清洁、保养、续费多少？ |
| 决策与情绪 | 我能少纠结一点，还是多了一套不断比较、担心的任务？ |
| 机会 | 选了它，哪些更重要的安排会被挤掉？ |
| 健康与安全风险 | 今天便宜了，会不会把代价留给身体、安全和未来？ |

不仅记录减少的成本，也记录增加的成本。少花钱却多花时间，不会自动变好或变坏，要看你眼前最需要保住什么。

同一次维修会同时占用钱、时间和精力，但“维修成本”不是再额外加一笔。机会成本也不能把已经记过的支出重复累计。

不用把一切都换算成小数点后的金额。你只要看见：**少花的钱，有没有从别的地方加倍收回来。**

## 3. 对照真正的生活品质

把变化落到真实体验上：健康、睡眠、营养、舒适、安全、便利、时间自主、情绪状态、重要关系、真实体验、稳定性、长期可持续性。

例如，一件二手物品价格低，但无法确认安全状态、使用起来总故障，不能仅凭价格判断它符合“过学”。合理花钱买更可靠的高频用品，也可能让总成本更低、生活更舒服。

每次判断至少写清：**保住了什么，改善了什么，可能损失什么。** 收益还不确定，就写条件和未知，不把“可能”改成“肯定”。

完整定义和几个对照例子，见[成本与品质](./成本与品质.md)。

## 4. 先守底线，再谈划算

一个办法如果明显牺牲健康、安全、基本营养、合理睡眠、基本居住质量、必要医疗、长期财务安全或真正重要的关系，再便宜也不能算好办法。

有些代价今天不会找上门。短期省钱、长期添麻烦，也要放进判断里。

涉及身体、营养或医疗的主张，不能只靠“我试过，没事”就劝别人跟着做。

## 5. 给结论留条件

判断一个方法，可以用下面四种状态。它们描述的是具体主张，不能拿来给人分高低。

| 状态 | 怎么理解 |
| --- | --- |
| 正式收录 | 主张、实际价值与边界比较清楚，可以进入实践篇；仍要看个人情况。 |
| 有条件收录 | 在写明的条件下有用，超出条件就可能不合适。 |
| 观察中 | 具体主张、效果或风险还不够清楚，先留着继续了解。 |
| 不予收录 | 当前主张明显碰到原则或底线，需要说明具体原因。 |

找到作者，不等于这个办法适合每个人。暂时没找到出处，也不用把名字当成禁词：先把能说清的部分说清，缺的地方留着补。

有新材料就更新判断。把一句话写进书里，不等于给它办了终身会员。

| 方法 | 重点看什么 | 当前状态 |

| [二手 / 咸鱼消费](./04-过日子的具体方法/04-二手消费.md) | 真实需求、实际成色、交易风险与总成本 | 有条件收录 |

## 7. 网络理论和整理的方法，都可以讨论

有具体网络主张的，标为**已有网络理论**，列作者与来源；本项目按总纲归纳的，标为**“过学”实践方法**。后者表示项目整理，不表示这招是我们全球首创。

先查有没有类似方法，再判断要不要新增。一个不同场景，可以补进已有领域页；别为同一个方法重新起五个“理论”名。

结论应同时带上适用人群、不要照搬的情况和退出方式。进入[行为指南](./行为指南/README.md)，也要写明具体行动，而不只留下一个状态标签。

## 8. 你也可以带一个新方法来

发现值得讨论的生活主张，可以在 [GitHub 提交 Issue](https://github.com/Allen-boan/guoxue/issues/new/choose)。写清名称、它解决的问题、你觉得有用的地方、可能的代价和相关来源就够了。

已经有类似条目时，也可以补一个不同场景的例子。不必给每个好办法重新起个大名字。

完整投稿格式见[参与指南](../CONTRIBUTING.md)。

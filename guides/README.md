# 生活方法登记与写作模板

读者正文在[第二章：过日子的办法](../docs/02-过日子的办法/README.md)。网络理论和日常做法在同一生活问题下展开，此目录保存结构化登记和维护模板。

## 内容定位

[registry.yaml](./registry.yaml) 的 `domains` 保存生活领域及入口路径；`guides` 保存具体方法的稳定 id、来源类型、成本与品质变化、风险及正文位置。每个方法以 `doc_path` 和 `anchor` 定位；新增内容优先补充已有段落。

| 来源类型 | 维护方式 |
| --- | --- |
| `internet_theory` | 通过 `theory_id` 引用[理论登记](../theories/registry.yaml)，两类登记指向同一正文段落，作者、来源、实践与边界在该段维护。 |
| `guoxue_practice` | 本项目依据生活品质判断整理的日常方法，不宣称全球首创。 |

租房仍是租万物的子项，正文位于消费购物页的租万物部分。居住页可以提供入口；`category` 用于领域检索，不要求与 `doc_path` 所在领域一致。有限实践解释不等于同名网络主张已经全面核验。

## 同步维护

参考[方法模板](./TEMPLATE.md)，正文从具体生活问题谈起，把选择、做法和条件连贯地说清楚，不统一套用固定小标题或步骤数量。唯一规则是 `P01 · 生活品质改善原则`；保住品质并减少无效负担、合理增加投入改善品质、有依据的短期投入换取长期改善，都可以成立。

成本与品质维度使用[核心规则](../constitution/core-principles.yaml)的 id，仅填实际相关项；维度标签不代替品质收益的依据，同一支出不重复计账。健康、安全等底线是 P01 的判断边界。

更新时同步正文位置、来源关系和风险说明。引用网络理论的方法与理论条目必须保持相同的 `doc_path`、`anchor`；不复制一份理论正文再写一份行动正文。改变收录状态需要维护者审核。当前没有 Agent 自动写入或发布。

# 行动方法登记与写作模板

读者正文在[第三章：日常行动](../docs/03-日常行动/README.md)。此目录保存结构化登记和维护模板。

## 内容定位

[registry.yaml](./registry.yaml) 的 `domains` 保存生活领域及正文路径；`guides` 保存具体方法的稳定 id、来源类型、成本与品质变化、风险及正文位置。每个方法以 `doc_path` 和 `anchor` 定位；新增内容优先补充已有段落，不机械地一条建议建一个文件。

| 来源类型 | 维护方式 |
| --- | --- |
| `internet_theory` | 通过 `theory_id` 引用[理论登记](../theories/registry.yaml)，作者与来源由对应理论正文维护。 |
| `guoxue_practice` | 本项目依据生活品质判断整理的日常方法，不宣称全球首创。 |

租房仍是租万物的子项，在居住领域的行动入口不改变理论层级。有限实践入口不等于同名网络主张已经全面核验。

## 同步维护

参考[方法模板](./TEMPLATE.md)，正文围绕具体问题、实际步骤、品质与成本取舍、适用边界展开，登记字段留在底层。唯一规则是 `P01 · 生活品质改善原则`；保住品质并减少无效负担、合理增加投入改善品质、有依据的短期投入换取长期改善，都可以成立。

成本与品质维度使用[核心规则](../constitution/core-principles.yaml)的 id，仅填实际相关项；维度标签不代替品质收益的依据，同一支出不重复计账。健康、安全等底线是 P01 的判断边界。

更新时同步正文位置、来源关系和风险说明；改变收录状态需要维护者审核。当前没有 Agent 自动写入或发布。

登记版本：`0.2.0` · 核心规则：`0.3.0` · 理论登记：`0.5.0`。

# 行为登记与写作模板

面向读者的内容在[《“过的人”行为指南》](../docs/行为指南/README.md)。这里保存它的结构化登记和写作模板，方便同步维护。

## 一个领域，多种方法

18 个生活领域各有一篇正文，一篇可以容纳多种方法。每种方法在[registry.yaml](./registry.yaml) 中保留独立 id，借 `doc_path` 与 `anchor` 定位到领域页中的具体段落。新增内容优先补充现有方法或领域页，不机械地一条建议建一个文件。

登记文件包含两个列表：

- `domains`：领域的 `id`、`name`、`doc_path`，对应公开目录。
- `guides`：具体方法的来源类型、成本与品质维度、适用条件、风险、建议和正文位置。

## 两种来源类型

| 登记值 | 含义 |
| --- | --- |
| `internet_theory` | 已有网络理论或实践讨论；通过 `theory_id` 引用理论登记，作者与原始来源在对应正文说明。 |
| `guoxue_practice` | 本项目按“过学”总纲组织的实践方法；可以采用常见生活方法，不宣称全球首创。 |

网络理论在行为指南中保留行动入口，完整主张、来源和收录状态仍由[理论登记](../theories/registry.yaml)维护。租房在居住领域提供入口，同时保持租万物的子项关系；领域分类不改变理论层级。

## 同步维护

1. 先读领域页，检查是否已经有相同方法。
2. 参考[行为模板](./TEMPLATE.md)写清问题、成本增减、品质变化和可执行步骤。
3. 同步登记。原则编号与维度 id 使用[核心规则](../constitution/core-principles.yaml)中的值，只填相关项。
4. 检查正文位置、来源关系与适用边界。改变收录状态需要维护者审核；目前没有 Agent 自动写入或发布。

维度是观察角度，不是成绩单。维修可能同时涉及金钱、时间与维护，标签可以关联，计算支出和用时则不能重复相加。健康和安全先守住，其他收益不能抵消明显风险。

本轮登记版本为 `0.1.0`，使用核心规则 `0.2.0`、理论登记 `0.4.0`。此目录负责维护信息，日常阅读从电子书入口进入。

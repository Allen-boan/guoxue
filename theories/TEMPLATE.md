# 新理论整理模板

这是内容维护者使用的模板。普通网友直接[提交新理论](https://github.com/Allen-boan/guoxue/issues/new?template=new-theory.yml)即可，不需要改文件，也不需要懂 Git。

新理论先进入“观察中”，不要把模板里的空位改成推测出的作者、日期或数据。涉及健康、安全、医疗时，先核查风险，再讨论是否省钱。

```yaml
id: 待填写唯一英文标识
name: 待填写理论名称
aliases: []
category: 待填写
summary: 待填写一句话介绍
status: observation
compatibility: uncertain
source_type: internet_term_unverified
sources: []
source_note: 准确出处待补充。
core_principles: []
benefits: []
risks: []
boundaries: []
recommendation: 尚未建议正式收录，待核查定义、来源与适用边界。
review_status: pending_human_review
page: 待填写对应页面路径
```

`status` 是收录处理，`compatibility` 是相容性判断，两个字段不能混用。合法状态见 [registry.yaml](./registry.yaml)。只有经过核查的真实来源才放入 `sources`；建议记录 URL、标题、来源主体、访问日期，以及“原始主张 / 转述 / 专业资料”的角色。暂时不知道源头时保留空数组，不生成虚假链接。

以下内容可复制到新的公开文章中。

# 〔理论名称〕

> 〔一句话说清它想解决的生活问题。〕

**当前状态：观察中** · **来源：准确出处待补充。**

## 1. 这是什么

写出能被判断的具体主张。同名说法有多个版本时，说明本文评估哪一个版本。原主张和过学提出的改良解释分开写。

## 2. 它解决什么现实问题

用普通人的场景说明：谁遇到什么问题，原本耗费了哪些钱、时间、精力或注意力。

## 3. 为什么会流行

有来源就引用。没有传播资料时，只能写“可能吸引人的原因”，明确这是分析，不冒充已经验证的传播史。

## 4. 它最有价值的部分是什么

写清真实改善，不用“研究表明”“全网都在用”等无证据表述。

## 5. 它是否符合过学

给出“符合 / 部分符合 / 不符合 / 继续观察”，逐条连接主张、证据和原则。便宜不是充分理由；资料不足时不能强行下结论。

## 6. 它对应哪些过学原则

用原则编号与名称，例如 `P06 · 长期成本原则`。同时写出冲突原则；不要只罗列有利编号。

## 7. 普通人怎么实践

给出可以执行的小步骤，交代必要成本、核查点和退出方式。健康内容不提供人人通用的剂量、训练强度或疗效承诺。

## 8. 什么情况下不要照搬

列出收入、家庭责任、身体情况、城市、使用频率等重要差异。适用范围越窄，越要说清楚。

## 9. 它有什么边界

检查健康、安全、基本营养、合理睡眠、基本居住质量、必要医疗、长期财务安全和重要关系。算长期总账，不掩盖风险。

## 10. 它在过学体系中属于什么位置

说明栏目、实践领域、与已有理论的区别或重复，以及是否建议正式收录。状态变化须经人工审核；文章末尾记录决定理由和仍待确认的事项。

## 来源与待核事项

- 准确出处：待补充。
- 原理论定义：待核查。
- 可核查资料：仅列真实链接；没有就注明暂无。
- 当前整理：初版编辑整理，待人工复核。

更新时保留此前判断的变化理由，不把“未发现风险”写成“证明没有风险”。

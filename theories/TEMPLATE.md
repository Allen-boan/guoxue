# 新理论整理模板

这是内容维护者使用的模板。普通网友直接[提交新理论](https://github.com/Allen-boan/guoxue/issues/new?template=new-theory.yml)即可，不需要改文件，也不需要懂 Git。

新理论先进入“观察中”。先说清原主张，再检查硬边界和成本—品质变化，不把模板里的空位改成推测出的作者、日期或数据。同一方法已有文章时优先补充；本项目组织的行为方法使用[行为模板](../guides/TEMPLATE.md)。

```yaml
id: 待填写唯一英文标识
name: 待填写理论名称
aliases: []
parent_id: null
child_ids: []
category: 待填写
summary: 待填写一句话介绍
status: observation
compatibility: uncertain
source_type: internet_theory
source_evidence_type: 待填写实际证据情况
sources: []
source_note: 作者与原始来源待补充。
cost_dimensions: []
quality_dimensions: []
cost_changes:
  reduced: []
  increased: []
quality_effects:
  maintained: []
  improved: []
core_principles: []
benefits: []
risks: []
boundaries: []
applicable_when: []
not_applicable_when: []
recommendation: 尚未建议正式收录，待核查定义、来源与适用边界。
review_status: pending_human_review
page: 待填写对应页面路径
doc_path: 与 page 填写同一路径
```

`parent_id` 留空表示主项；具体场景归入已有主项时填写其 id，并同步主项的 `child_ids`。

`status` 是收录处理，`compatibility` 记录是否符合原则，两个字段不能混用。合法状态见 [registry.yaml](./registry.yaml)。`internet_theory` 描述内容类型，不表示来源已核验；`source_evidence_type`、`sources` 与待补事项记录实际证据情况。只有真实来源才放入 `sources`；记录 URL、标题、作者或来源主体，以及“原始主张 / 转述 / 专业资料”的角色。暂时不知道源头时保留空数组，不生成虚假链接。

成本与品质维度使用 [constitution/core-principles.yaml](../constitution/core-principles.yaml) 中的 id，只填实际相关项。维度标签不等于改善结论；用 `cost_changes` 写减少与增加，用 `quality_effects` 写维持与改善，并在风险和边界中交代可能损失。需要时可增加计算假设或未知项，不编出统一评分和确定收益。维护费用与金钱、时间的关联可以同时标记，计算总账时同一笔支出不重复相加。

以下内容可复制到新的公开文章中。

# 〔理论名称〕

> 〔一句话说清它想解决的生活问题。〕

**当前状态：观察中** · **来源类型：已有网络理论**

## 1. 这是什么

写出能被判断的具体主张。同名说法有多个版本时，说明本文评估哪一个版本。原主张和“过学”提出的改良解释分开写。

## 2. 它解决什么现实问题

用普通人的场景说明：谁遇到什么问题，当前方案的综合成本和真实生活体验是什么。

## 3. 为什么会流行

有来源就引用。没有传播资料时，只能写“可能吸引人的原因”，明确这是分析，不冒充已经验证的传播史。

## 4. 它最有价值的部分是什么

分别写清：

- 降低哪些成本，又增加哪些成本。
- 维持或改善哪些品质，又可能损失什么。
- 这些变化需要什么条件；目前哪些只能说“可能”。

不要用“研究表明”“全网都在用”等无证据表述。

## 5. 它是否符合“过学”

先检查健康、安全及其他硬边界，再给出“符合 / 部分符合 / 不符合 / 继续观察”，逐条连接主张、证据、成本—品质变化和原则。合理的品质投入可以增加金钱成本；便宜不是充分理由。资料不足时不能强行下结论，也不能用其他收益抵消明显安全风险。

## 6. 它对应哪些“过学”原则

用原则编号与名称，例如 `P06 · 长期成本原则`。同时写出冲突原则；不要只罗列有利编号。

## 7. 普通人怎么实践

给出可以执行的小步骤，交代必要成本、核查点和退出方式。健康内容不提供人人通用的剂量、训练强度或疗效承诺。

## 8. 什么情况下不要照搬

列出收入、家庭责任、身体情况、城市、使用频率等重要差异。适用范围越窄，越要说清楚。

## 9. 它有什么边界

检查健康、安全、基本营养、合理睡眠、基本居住质量、必要医疗、长期财务安全和重要关系。算长期总账，不掩盖风险。

## 10. 它在“过学”体系中属于什么位置

说明栏目、实践领域、与已有理论及行为方法的区别或重复，以及是否建议正式收录。需要行动入口时链接到对应行为领域，避免复制整篇。租房属于租万物的子项。状态变化须经人工审核；文章末尾记录决定理由和仍待确认的事项。

## 作者与来源

- 作者：待补充。
- 来源：待补充。
- 相关资料：仅列真实链接；没有就留空。


更新时保留此前判断的变化理由，不把“未发现风险”写成“证明没有风险”。

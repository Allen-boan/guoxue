## 前言

一件东西买得便宜，却要反复修；另一件贵一点，天天用着舒服。光看价签，很难分清哪笔钱花得值。

**我们研究的不仅仅是怎么把日子过便宜，更是怎么用更低的综合成本，提升我们的生活品质。**

喝水、睡觉、租房、买东西，表面上各是各的事，最后都要落到同一个结果：人是否过得更健康、更舒服、更省心。钱和精力就那么多，把不值得的消耗减下来，重要的事才有余地。

# “过的人”行动指南

**“过学”｜过日子的学问**

**“过的人”｜全民大过日子时代**

> **生活成本可以低，生活品质不能低。**

买东西、租房、吃饭、睡觉，每天都在花钱，也在花时间和精力。

“过学”想研究的是：哪些花得值得，哪些只是白忙。不是把日子过得越便宜越好，而是把资源留给真正影响生活品质的事。

互联网里已经有不少具体方法：大水、长睡眠、薄肌、低成本租房、二手、租万物……这本指南把它们放在一起，先讲判断的方法，再谈具体怎么做。

**混的人混社会，我们过日子。**

## 怎么读

第一次来，按前三章顺着读：先认识“过学”，再看总纲，最后拿到十条判断原则。

有具体问题，就直接翻第四章。读完觉得某个方法值得试，先小范围尝试，再看看它有没有让自己的日子更好过。

总纲讲目标，原则帮助判断，具体方法解决不同问题。一种方法可能用到好几条原则，不需要硬分成一一对应的派别。

**“过的人”不是一个消费等级，也不需要领证。** 喜欢真有用的东西，愿意为重要的品质花钱，不太想为别人的眼光添负担，你可能早就在这样过日子了。

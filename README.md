# 过学

**过的人｜全民大过日子时代**

> **生活成本可以低，生活品质不能低。**

互联网出现了越来越多看似不同的生活理论：
大水、长睡眠、薄肌、低成本租房、二手、租万物……

过学试图做一件事：**把这些分散的生活方法背后的共同逻辑总结出来。**

我们研究的不是怎么把日子过便宜，而是怎么把钱、时间和精力，花到真正影响生活品质的地方。

**混的人混社会，我们过日子。**

## 过学是什么

过学研究普通人如何用更低的生活成本、更低的维护成本、更少的无效消耗，获得、维持甚至提升真正的生活品质。

**不是少花钱，是少给不重要的东西花钱。**

该省的地方狠狠省，真正影响生活品质的地方别亏待自己。去掉不必要的溢价、排场和人设维护，把资源留给自己的真实需要。

便宜不自动符合过学，贵也不自动违反过学。核心判断是“值不值”，不是统一的价格线。

每天使用、确实改善舒适度、预算承受得住的 3000 元床垫，可能值得。为拍照买的闲置摆设，哪怕便宜，也可能不值。

## 十条基本原则

1. **生活品质优先：**省成本，不能把品质省没了。
2. **去无效溢价：**保留真正有用的品质和服务，砍掉不需要的展示成本。
3. **核心需求优先：**先搞清楚要解决什么，再考虑买什么。
4. **低维护：**清洁、收纳、修理和人设，都有后续成本。
5. **资源集中：**把钱、时间、精力和注意力放到真正重要的地方。
6. **长期成本：**算总账，不只看付款那一刻。
7. **真实使用价值：**用得上，才有机会值。
8. **因人而异：**别人的最优解，不一定是你的。
9. **不以吃苦为荣：**没有必要为了省钱证明自己多能忍。
10. **不为别人眼里的体面买单：**自己的日子，不用一直给观众看。

健康、安全、基本营养、合理睡眠、基本居住质量、必要医疗、长期财务安全和真正重要的人际关系，是底线。短期便宜、长期代价更高的办法，通常不符合过学。

```text
   ├─ 长睡眠理论：原始主张核查中，观察中
   ├─ 薄肌理论：训练、正反馈与掌控感（邵艾伦 Alan）
   ├─ 低成本租房：居住与通勤的总账
   ├─ 二手 / 咸鱼：购买使用价值
   └─ 租万物：低频需求与拥有成本
```

已有方法不是被过学否定，而是被认真整理：有价值的部分、适用条件和不能照搬的地方，一起写清。

第一版设有六个条目：**四项有条件收录，两项观察中**，待发起人复核。大水与长睡眠的原始主张还在核查，页面的过学实践分析不替原作者定义。已定位的本人原视频会注明作者和链接；未确认的出处继续核查，不编作者、日期或热度。

## 给维护者的说明

**Human First，Agent Ready。** 公开内容先服务读者，机器规则放在底层。

- 网站：VitePress 静态站，无数据库、无后端、无 AI API。
- 内容：`docs/`，按入门、总纲、原则、实践、新论、决议组织。
- 规则：[constitution/core-principles.yaml](constitution/core-principles.yaml)。
- 理论登记：[theories/registry.yaml](theories/registry.yaml)，首页卡片和决议列表在构建时读取此文件。
- 未来 Agent：[agent-spec/README.md](agent-spec/README.md)，**本阶段仅有规范，没有实现**。
- 部署：[GitHub Pages 工作流](.github/workflows/pages.yml)。

本地使用 Node.js 22 或更高版本：

```bash
npm ci
npm run dev
```

仓库已包含实际构建生成的 `package-lock.json`，使用 `npm ci` 保持依赖一致。打开终端显示的本地网址。静态构建与预览：

```bash
npm run build
npm run preview
```

GitHub 仓库的 **Settings → Pages → Source** 选择 **GitHub Actions**。推送到 `main` 自动检查内容、构建并部署；PR 只做检查，不发布。首次启用、权限要求与更换站点路径见[维护说明](docs/maintenance.md)。

内容与代码的授权条款待发起人确认；目前未擅自添加许可证。公开协作可以先提 Issue 或 PR，转载许可请先联系发起人。
